# 仿石蘑菇 最终定稿（适配洛克王国世界防御冷却机制｜纯土系、物攻120、速度87、防御技能共享1回合冷却、释放防御技能全程90%减伤）
## 一、基础档案
1. 名称：仿石蘑菇
2. 属性：纯土系（仅外形是蘑菇，本体矿化岩石生物）
3. 栖息：林间泥地、山地碎石坡，野外普通捕捉宠，无稀有限定
4. 生态设定：扎根泥土仅露出矿石蘑菇伞伪装岩石；开启防御技能时伞盖闭合形成硬质岩盾，开启期间大幅减免伤害；所有防御技能共享1回合全局冷却，无法连续开启
5. 两段进化
一阶：小石菇（捕捉初始幼体）
二阶：仿石蘑菇（完全体）
6. 固定硬性数值：速度87、物攻下调至120，种族其余不变

推荐性格：固执（+物攻-魔攻）；努力分配：252物攻、252物防、6精力

## 三、两段外观（无改动）
1. 一阶·小石菇：迷你灰白色矿质蘑菇伞，扎根泥土伪装碎石，无攻击性。
2. 二阶·仿石蘑菇：巨型硬化岩层蘑菇伞，根茎裹厚土层；开启防御时伞盖完全闭合，隔绝冲击，周身泥土粉尘。

## 四、专属特性【岩菇坚盾】（适配洛克世界防御冷却规则，修正单回合限制）
### 完整规则
1. 自身**场上存在任意防御类变化技能护盾/扎根/物防强化/免控盾持续期间**，受到所有威力伤害统一减少90%；护盾持续多回合，并非仅释放当回合生效。
2. 冷却机制（对标洛克世界标准规则）：任意防御技能使用后进入**1回合全局共享冷却**，所有防御技能同步转CD，冷却阶段无法释放任何防御技能，真空期无90%高额减伤。
3. 仅防御类变化技能可触发90%减伤；输出、干扰技能不产生护盾，无减伤效果。
4. 切换离场、阵亡直接清除所有护盾与减伤状态，离场不保留护盾。

### 配套多重制衡枷锁（解决90%高额减伤强度隐患，不超模）
1. **强制1回合真空冷却，无法无限循环护盾**
开完任意防御盾后，下回合全体防御技能锁CD，这一回合完全裸身承伤，三重双倍弱点会被直接打残；对手可抓住冷却回合爆发秒杀。
2. 防御技能PP总量稀缺
携带2个防御技能，合计PP仅7，长线BOSS战很快耗尽护盾资源，后期全程无高额减伤。
3. 纯土系三重致命双倍弱点：水、草、格斗
90%减伤只能抵挡一轮爆发，冷却真空期双倍伤害，132血量扛不住两轮特攻；极冰雪熊、花草土龟耐久、续航、团队辅助全方位碾压它。
4. 输出底层硬伤，无翻盘能力
物攻120无增伤，只能单纯承伤消耗，无法单人单刷全地图，必须搭配水晶蝶、净水鱼等输出宠补伤害。
5. 无团队辅助能力，仅自保
不像花草土龟离场给全队双抗、萤花仙全队回PP，只能保护自身，无法带动队伍体系。

## 六、配套配招（贴合1回合共享冷却机制）
1. 岩伞撞击（土系物攻大招，威力130，核心输出，释放无护盾、进入真空期）
2. 土层坚壳【防御技】PP3：护盾持续2回合，释放后全体防御1回合冷却，护盾存续期间90%减伤，提升1级物防
3. 岩土扎根【防御技】PP4：护盾持续2回合，释放后全体防御1回合冷却，护盾存续期间90%减伤，回合末回血4%最大生命
4. 碎石震荡（干扰，降低敌方1级物攻，不触发护盾、无减伤）

### 循环逻辑举例
回合1：释放土层坚壳→获得2回合90%减伤，全体防御进入1回合冷却
回合2：冷却锁死，无法开任何防御，护盾仍存续，可输出
回合3：冷却结束，但土层坚壳护盾已到期，可再次释放岩土扎根续盾，再次触发1回合冷却
循环存在固定1回合无操作真空窗口，无法无缝永续护盾。

## 七、全方位强度评价
### 一、机制优势，贴合洛克世界设定
1. 生态逻辑闭环：矿石蘑菇闭合岩盾获得高额持续减伤，防御共享1回合冷却完全对标游戏原生机制，玩家上手易懂。
2. 开荒对抗电、金、火系物理怪体验优秀，护盾存续期间几乎不掉血，完美弥补新手全队弱电短板。
3. 纯土系功能型前排，可搭配花草土龟、萤花仙组成草土续航联防体系。

### 二、多重硬性短板牢牢锁死强度，不会前期无敌、挤压其他精灵价值
1. **冷却真空期是最大破绽，不存在无缝永续90%减伤**
每续一次护盾，强制空一回合无法开防御，高速草、水、格斗宠会抓住冷却回合先手双倍爆发，轻松压低血量甚至直接击杀。
2. 三重主流属性双倍克制，环境天敌极多
森林、山地、天梯高频刷新草、水系、格斗精灵，真空期极易暴毙，单宠推图会频繁卡关，倒逼玩家培养其他捕捉宠。
3. 输出能力严重不足，无单刷能力
物攻仅120，特性不加任何伤害，只能承担承伤功能，清图效率远低于水晶蝶、极冰雪熊等输出核心。
4. 护盾PP总量有限，长线作战疲软
两个防御技能合计7次使用机会，高血量BOSS战消耗完毕后，全程裸身承伤，失去核心生存手段。
5. 无团队增益，定位单一挂件
对比花草土龟退场全队双抗、萤花仙全队回能耗，仿石蘑菇只能自保，队伍不可替代性极低。

### 三、分场景精准定位
1. PVE开荒：T2功能性前排
对付电、金、火系物理野怪手感优秀；遇到草、水、格斗BOSS必须频繁换宠联防，无法单人通吃全地图，不会取代极冰雪熊开荒核心地位。
2. PVP天梯对战：T2娱乐消耗挂件
慢速土系消耗队可用，依靠持续90%减伤抵挡爆发；但快攻草、格斗、水系体系完美克制，冷却真空期会被直接斩杀，无法作为上分主力。

## 八、综合总结
1. 完全满足修改需求：纯土蘑菇外形、物攻120、速度87、防御技能护盾存续期间90%减伤，遵循洛克世界防御共享1回合冷却规则，取消单回合限制；
2. 90%高额持续减伤看似强势，但**全局1回合共享冷却真空、护盾PP稀缺、三重双倍弱点、输出拉胯**四重制衡强力控强，整体均衡可控，不会出现前期无解碾压；
3. 定位特化自保土系承伤辅助，有独特机制但存在清晰天敌，和极冰雪熊、花草土龟形成稳定强度分层，所有野外精灵均保留不可替代价值，可直接定稿使用。
