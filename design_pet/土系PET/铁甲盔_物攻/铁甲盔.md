# 铁甲盔 完整精灵定稿
## 一、基础档案
名称：铁甲盔
属性：纯地系
生态：凶性虫类，对人类敌意极强。一阶是满地爬行的小虫，背部天生厚重硬质虫甲，无攻击欲望但会扎堆骚扰行人；二阶进化后双足直立，前肢硬化形成锋利单刃虫刀，看见人类直接主动挥刀进攻，依靠厚重甲壳扛伤近身劈砍。
进化链：碎背虫（一阶）→铁甲盔（最终形态）
定位：中慢速耐久物攻打手，奇数回合高额双防获得极强站场能力，偶数回合防御大幅下滑存在明显破绽，标准T1强度，不超模。
定位核心：靠回合机制分段抗压，依赖奇数回合苟活输出，偶数回合是致命短板。

## 二、定型种族值
精力122 / 物攻132 / 魔攻65 / 物防90 / 魔防88 / 速度58
种族总和：122+132+65+90+88+68 = 555
### 面板解析
1. 物攻132上游输出底子，纯物攻单路线，魔攻完全废弃；
2. 速度68低速梯队，绝大多数高速精灵稳定先手，只能被动承受首轮伤害；
3. 裸身双防仅90/88属于普通水平，血量122提供基础容错，**全靠特性奇数回合高额双防撑起耐久**；
4. 纯地系固定三大双倍弱点：水、草、格斗，克制属性环境随处可见。
推荐性格：悠闲（+物防-速度）
努力分配：252物攻、252精力、6物防

## 三、两段外观
1. 一阶·碎背虫：小型多足爬虫，通体深褐，背部覆盖分层厚重甲壳，成群在道路、泥土中爬行，不会主动攻击人类，但会大量聚集阻碍通行。
2. 二阶·铁甲盔：两米高直立虫形生物，躯干布满拼接式金属质感硬甲；后肢粗壮支撑身体，单侧前肢硬化为狭长虫壳单刀，甲壳缝隙流出土褐色黏液，视野内出现人类就会主动挥刀冲锋。

## 四、专属特性【奇甲固守】完整规则
战斗回合判定：奇数回合（第1、3、5、7…回合）自身物防+50、魔防+50；
1. 加成仅在当前奇数回合生效，进入偶数回合立刻清除全部双防加成，裸身承伤；
2. 加成离场清空，再次上场重新按照场上回合数字判定；
3. 无层数、叠加机制，仅根据回合奇偶切换防御面板；
4. 特性仅提升双防，不提供攻击、速度、续航、免控任何额外增益。

### 制衡枷锁（锁死T1，杜绝T0超模）
1. 防御分段割裂，偶数回合极度脆弱
奇数回合坦度拉满，但偶数回合直接退回裸身双防，水、草、格斗双倍伤害能快速压低血量，对手可以卡偶数回合集中爆发斩杀。
2. 速度68低速，首轮为第1回合（奇数有防御），但后续对手持续先手，每两回合就有一回合无护盾空档；
3. 无任何续航、回血、减伤手段，仅靠回合提供临时双防，持续消耗战血量持续下滑；
4. 纯地系三大主流双倍弱点，即便奇数回合高额双防，双倍倍率依旧能打出可观伤害，无法做到完全无伤；
5. 无团队辅助能力，仅自身分段抗压，不能给队友提供任何增益。

## 五、纯地系属性攻防
进攻双倍克制：电、火、岩
防御三大2倍致命弱点：水、草、格斗
属性抵抗：毒、岩

## 六、适配配招
1. 裂土斩（地系物攻130，核心近战输出）
2. 硬甲格挡（防御变化，2回合小额减伤，弥补偶数回合防御缺口）
3. 泥雾迟缓（干扰，降低敌方1级速度，小幅缓解低速劣势）
4. 土痂自愈（回合末回复7%生命值，小额兜底续航）

## 七、全方位强度评价（是否超模）
### 前置结论：完全不超模，稳定标准T1，机制有特色但破绽巨大，不存在无解压制力
### 一、机制优势
1. 贴合甲壳设定：奇数回合收紧全身甲壳获得巨额防御，偶数回合舒展甲壳进攻，设定逻辑自洽；
2. 奇数回合坦度顶尖，对抗火、电、岩石物理系输出几乎很难被击杀，开荒火山、荒漠地图抗压能力极强；
3. 低速肉盾体系优质前排，配合高速队友补伤害，奇数回合稳定扛下全套爆发。

### 二、不可弥补的多重短板，严格限制上限
1. 防御周期性真空是最大破绽
每2回合必然出现一回合裸身状态，对手完全可以规划输出节奏，卡在偶数回合集火，轻松打残甚至直接击杀，无法永续站场；
2. 低速天生被动挨打，节奏完全掌握在对手手中
速度68，高速草、水、格斗精灵全程先手，能精准把控回合节奏，稳定抓住偶数回合输出；
3. 高额双防挡不住双倍克制伤害
水、草、格斗双倍伤害倍率会大幅抵消+50双防的优势，奇数回合也扛不住多段克制爆发；
4. 缺少主动续航，长线对局持续掉血
仅一招微量回合回血，没有大额恢复手段，多轮奇偶循环后血量见底，失去作战能力；
5. 泛用性受限，遇到克制体系直接作废
森林、水域地图草、水系精灵遍地，很难发挥坦度优势，只能限定荒漠、火山场景使用。

### 三、分场景定位
1. PVE开荒：T1特化耐久物攻手
荒漠、火山电/火系BOSS战发挥优秀，奇数回合稳定扛伤输出；森林、水域草/水精英极易卡在偶数回合将其秒杀，无法单人全图通关。
2. PVP天梯：T1慢速消耗队专用前排
慢速地系、火系消耗队适配，用来扛首轮爆发；天梯主流草、水、格斗快攻完美克制，极易被卡回合斩杀，无法作为通用上分核心。

## 八、综合总结
1. 满足全部设计需求：纯地系凶性虫类，一阶爬虫厚背盔甲、二阶直立持单刀物攻手，特性奇数回合自身双防+50；
2. 高额双防看着强势，但**偶数回合防御清零、低速被动挨打、三重双倍弱点、无大额续航**多层制衡完整锁死强度，不会达到T0；
3. 机制辨识度高，回合交替攻防的设计有独特战术玩法，和三地鼠、仿石蘑菇等地系精灵形成清晰强度分层，环境平衡可控，可直接定稿使用。
