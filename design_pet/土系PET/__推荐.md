# 土 + 草双属性精灵全原型推荐（分四大类：植物真菌、穴居走兽、两栖爬虫、根茎共生幻想生物）

适配**新手村森林碎石坡、枯木腐土、林下潮土**栖息，完美贴合森林地形，兼顾萌新辨识度、土草属性逻辑，同时区分你已提到的**蘑菇、土龟、穿山甲**，附带定位与适配玩法。

## 一、你已提到的 3 种原型细化优化（优先可选）

### 1. 蘑菇（真菌 + 泥土共生，首选新手萌系消耗坦）

生态逻辑：腐木泥土里生长，菌根深埋土中，菌盖外露，**完美绑定土 + 草**，森林随处可见，新手第一眼好感拉满
三段进化思路：
一阶：土皮小孢（圆滚滚褐色土球，头顶极小嫩绿菌盖，浑身沾泥土）
二阶：泥纹伞菇（土褐色粗菌柄，伞盖带青苔纹路，根系扎进地面）
终形态：厚壤巨蕈（巨型圆胖菌体，菌盖铺满苔藓、草根，身体裹一层硬质泥土甲，低速肉坦）
定位：耐久消耗手，高双防、低速度，特性可以绑定场地回血，适配新手开荒抗压
优势：画风软萌无攻击性，机制简单，完美适配森林枯木栖息地

### 2. 土龟（龟甲覆土长草，均衡站场宠）

生态逻辑：常年趴在林下泥土，龟壳积满腐土，长出小草、苔藓，水陆两栖适配森林溪流碎石滩
设计区分普通乌龟：龟壳不是光硬甲，是**泥土层 + 植被**，四肢覆泥，背上长小型蕨类、野花
定位：均衡攻防，中低速，可物攻可辅助，能开护盾、铺青草场地
优势：厚重稳重，肉感足，和你水系熔岩鱼（龟鱼）画风配套

### 3. 穿山甲（挖地兽 + 背生藤蔓，物攻高速挖掘手）

生态逻辑：森林地底挖隧道，鳞片缝隙扎根藤蔓、野草，挖土时裹挟泥土，土属性拉满；体表生长草本植物
造型：棕褐泥土鳞片，脊背缠绕青绿藤蔓，爪子厚重挖土利器，尾巴长满杂草
定位：高速物攻手，主打挖洞、地面爆发技能，克制电、火系野怪
优势：动作灵动，输出手感好，弥补土草低速坦的输出短板

## 二、全新动物原型（蘑菇 / 龟 / 穿山甲之外，森林原生合理）

### 动物类 1：鼹鼠 / 地蚕（草石蚕原型，地底根茎啮齿）

原型参考甘露子（地蚕），地下块茎草本 + 穴居鼹鼠结合中国科学院...
外形：圆胖短肢鼹鼠，皮毛混泥土棕，背部长出一串根茎嫩芽，全身缠绕细草根，擅长钻土
栖息：森林地下土层，树根隧道，完全贴合土草环境
定位：高速物攻，擅长持续吸血、挖洞规避伤害，新手前期收割小怪好用

### 动物类 2：草原犬鼠（土拨鼠，群居土穴 + 洞口长草）

一群在地底筑巢，土堆洞口长满青草，头顶、后背覆盖短草
设计：圆胖土黄色土拨鼠，头顶一丛青草，脸颊沾泥土，可群居设定
定位：干扰辅助型，铺青草场地、降低敌方攻防，偏功能性，适合联防

### 动物类 3：蚯蚓巨蚓（地底软体生物，体表附苔藓孢子）

通体湿润褐土躯体，体表长满细小青苔、蕨类幼苗，钻过的泥土会快速长草
定位：纯消耗辅助，持续回血、给队友挂草系增伤，速度极慢极致肉盾

### 动物类 4：蝼蛄（土栖昆虫，背生草本绒毛）

森林泥土小虫，前爪挖土，背部绒毛附带草籽，移动一路长出小草
小型萌系，前期过渡精灵，低种族，纯过渡捕捉宠

## 三、纯植物原型（无动物，纯土生草本，温柔辅助款）

### 1. 块根人参 / 土豆（根茎人形块根精灵）

原型曼德拉草根、土豆块茎，深埋地下，顶部长出茎叶，全身是泥土包裹的肉质根茎
外形：人形圆胖块根，泥土外壳，头顶绿叶藤蔓，安静扎根土里，不会主动攻击
定位：纯魔攻辅助，续航、回血、场地特化，新手专属无限续航辅助

### 2. 金发藓（土马鬃苔藓丛）

大片丛生苔藓团，扎根岩石薄土，通体青绿，表面覆一层干土，风吹不掉
一团团蓬松土苔，周身散落草孢子，技能偏向群体护盾、持续回复

### 3. 地藤巨根（大树地下主根成精）

古树粗壮地底根系，裸露地表的根须长满地衣、小草，泥土包裹粗壮根须躯体
巨型长线型精灵，对标你的鎏金龙螭长条画风，可做双刀均衡手

## 四、两栖幻想生物（蛙类，森林水坑土坡通用）

泥沼蛙 / 土葫芦蛙：身体裹一层干硬泥土外壳，背部长出荷叶、小草，蹲在林下泥坑
土属性来自泥甲，草属性来自背部水生草本；平衡耐久 + 中等速度，攻防均衡，过渡百搭

## 六、最优成品完整设计方案（蘑菇款，直接落地新手村）

# 壤孢巨蕈 土 + 草 新手村专属肉坦精灵

### 栖息点位：森林西侧枯木碎石坡（和赤红焰蛹六翼火蛹同一片枯木区域）

### 三段进化

1. 一阶：土皮小孢（可直接捕捉）
拳头大褐色土球，表层沾细碎泥土，头顶一小撮嫩绿草芽，不会移动，躲在腐木缝隙里，呆萌无攻击性。

土褐色粗菌柄撑开小圆伞盖，伞盖边缘长出青苔，根系扎进泥土，能缓慢滚动移动。
3. 终形态：壤孢巨蕈
圆胖巨型菌体，厚重泥土层构成躯干，菌盖铺满苔藓、小蕨类、野花；底部无数根须扎根地面，周身持续散发青草孢子；整体敦实厚重，纯低速耐久坦。

总和：656，纯魔攻消耗，极致双防，站场续航

每回合结束恢复自身最大血量 8%；处于青草场地时，土、草技能威力 + 15，完美契合土草长线消耗定位

### 适配队伍价值

原有水 / 火 / 草 / 电队伍短板：怕电、怕物理爆发；此精灵**土系免疫电**，高额双防扛住岩石、地面物理输出，青草场地给全队草系增伤，完美补齐新手前期克制闭环。
