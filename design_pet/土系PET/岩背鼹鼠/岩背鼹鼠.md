# 岩背鼹鼠 优化后完整定稿（T3土系魔攻手｜双防上调至90、叠速离场不清零，其余全部保留原设定）
## 一、基础档案
1. 名称：岩背鼹鼠
2. 属性：纯土系
3. 栖息：森林、山地浅层泥土，野外随处可捕捉，普通小怪，无稀有获取门槛
4. 定位：纯T3娱乐整活精灵，依旧无开荒、天梯上分价值，仅趣味叠速玩法
5. 两段进化
一阶：小石鼹（捕捉初始）
二阶：岩背鼹鼠（最终形态）
6. 硬性固定数值：速度90、魔攻手，仅物防/魔防改为90，其余种族不变

## 二、定型种族值
精力92 / 物攻65 / 魔攻110 / 物防90 / 魔防90 / 速度80
种族总和：527
### 面板改动说明
1. 物防72→90、魔防74→90，小幅提升基础承伤能力，但血量92依旧偏低，整体还是脆皮；
2. 魔攻110、速度90、生命、物攻完全维持原下游水准，输出、基础速度没有补强；
3. 物攻65彻底作废，纯魔攻单路线，打击面仅电、金、火三类，泛用性极差。
推荐性格：保守（+魔攻-物攻）；努力分配：252魔攻、252速度、6精力

## 三、两段进化外观（无改动）
1. 一阶·小石鼹鼠
迷你土黄色小鼹鼠，背部零散碎石，擅长浅层钻土，外形朴素无特效。
2. 二阶·岩背鼹鼠
体型略大，背部覆盖整块粗糙岩层，前爪厚重挖土专用；平时埋土只露出岩石后背，周身常年飘泥土粉尘。

## 四、专属特性【岩掘提速】（核心改动：叠速层数离场不清除）
### 完整规则
1. 每释放一次土系威力输出技能，自身永久速度+10，层数无上限；
2. **自身切换离场、再上场，叠加的速度层数完全保留，不会清零**；仅阵亡时所有层数重置归零；
3. 只有土系威力攻击技能能叠加，变化、防控、干扰技能不计数；
4. 特性只提供速度加成，无任何物攻/魔攻/双防/回血/减伤附加效果。

### 关键制衡约束（保证依旧是T3，不会变强）
1. 阵亡直接清空全部叠层，一旦被击杀之前所有铺垫全部作废；
2. 仅提速不加伤害，魔攻基础110刮痧，哪怕叠到超高速度，斩杀能力依旧缺失；
3. 三重属性弱点不变：水、草、格斗双倍克制，天敌极多，很容易被高速对手先手秒杀打断叠层节奏；
4. 叠层只能靠输出技能，无法快速堆叠，前期铺垫回合成本极高；
5. 无团队辅助、无续航、无自保强化，功能单一，只能单打独斗叠速度。

进攻克制：电、金、火
防御三重2倍弱点：水、草、格斗
防御优势：免疫电系；抵抗火、金

## 七、全方位强度评价
### 1、本次改动带来的小幅提升点
1. 双防各提升18点，基础承伤小幅改善，不会被小怪一下秒，多1~2回合叠速度的容错；
2. 离场不清层是最大机制加强：可以分批上场叠层，叠几层切走保血，下次上场继续提速，整活套路顺滑度大幅提高，趣味度上升。

### 2、多重硬性短板牢牢锁死T3下水道定位，完全达不到可用主力水平
#### ① 输出底层硬伤无法解决
魔攻仅110，特性全程不加任何伤害，就算叠到190、200速度，打花草土龟、极冰雪熊等高耐久肉盾依旧刮痧，缺少核心斩杀能力，推图效率远低于同期所有主流精灵。

#### ② 血量短板致命，双防提升治标不治本
基础生命只有92，即便双防90，吃到水/草/格斗双倍克制伤害依旧两回合残血，一旦被击杀，辛苦叠加的速度全部清空，风险极高；
且野外、天梯大量高速草/水精灵，先手稳定压制，很难安稳叠高层数。

#### ③ 泛用性极低，完全无法替代任何主力
- 开荒土系有花草土龟（团队双抗增益、高耐久）、极冰雪熊（冰土广打击面、残血爆发、免疫电完美联防），两者输出、生存、功能性全方位碾压岩背鼹鼠；
- 对战缺少控场、续航、团队辅助，只有单纯叠高速的娱乐机制，面对主流阵容毫无竞争力；
- 打击面狭窄，龙、灵、妖精、冰全打不动，队伍必须额外搭配大量补盲精灵。

#### ④ 离场不清层仅提升娱乐性，不改变实战弱势
这个改动只是优化整活体验，没有解决输出低、血薄、三重弱点、成型慢四大核心缺陷；天梯对手只要携带格斗/草系高速宠，就能全程压制它，不让它安稳叠层，叠速机制很难发挥价值。

### 3、分场景定位
1. PVE开荒：纯T3垫底过渡宠，抓到直接仓管，培养资源完全浪费；仅无草/水/格斗的纯电、金属性场景临时过渡，无长期培养意义。
2. PVP天梯对战：T3纯娱乐挂件，完全没有上分能力，仅自定义对战玩叠高速趣味套路。

## 八、综合总结
1. 完全遵循你的修改需求：魔防90、物防90，其余种族不变；特性叠速离场不消失，阵亡才清零；
2. 改动仅小幅提升生存容错与整活流畅度，**整体依旧严格锁定T3下水道强度，不会超标**；
3. 机制趣味度更高，但底层输出、血量、属性多重短板无法弥补，不会挤压花草土龟、极冰雪熊等土系主力的出场空间；
4. 定位清晰：纯收藏、娱乐整活小怪，不具备开荒、对战核心价值，平衡可控可直接定稿。
