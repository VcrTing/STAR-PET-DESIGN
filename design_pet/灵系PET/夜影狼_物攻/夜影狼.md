# 夜影狼 优化定稿
## 一、基础档案
名称：夜影狼
属性：灵+地
生态：潜藏森林、山地交界深处的孤高凶狼，周身缠绕地底怨灵黑雾，爪裹挟岩土与幽影之力；只会孤身出没，3小时全图仅随机刷新1只，捕捉难度高，前期稀有精英物攻手。
进化链：幽土幼狼 → 夜影狼
定位：常态T1高速物攻手；满足触发条件上场直接双攻翻倍，成型后标准T0残局收割怪。
硬性数值：速度123，物攻核心；本次调整：物防110、魔防90、物攻140

## 二、定型种族值
精力118 / 物攻120 / 魔攻60 / 物防110 / 魔防90 / 速度102
总和：118+120+60+110+90+102 = 600
### 面板解析
1. 物攻上调至140，常态输出显著提升；物防拉到110，物理承伤大幅加强，魔防90中等水平，面对特攻依旧容易吃痛。
2. 速度123高速梯队，绝大多数常规精灵无法先手压制它。
3. 纯物攻取向，魔攻完全放弃；灵+地打击面广，但保留水、飞行、妖精三大双倍致命弱点作为平衡枷锁。
推荐性格：开朗（+速度-魔攻）
努力分配：252物攻、252速度、6精力

## 三、两段外观（不变）
一阶·幽土幼狼：灰黑小狼，皮毛沾泥土，黑雾稀薄，威胁极低；
二阶·夜影狼：高大孤狼，黑毛泛暗紫光斑，四肢裹岩土碎块，周身漂浮怨灵黑影，从林间阴影骤然跃出扑杀。

## 四、专属特性【孤魂狂啸】新版完整规则
触发判定二选一，满足任意一条，**上场瞬间直接获得双攻+100%（物攻、魔攻数值翻倍）**
1. 当前场上己方队友全部阵亡，只剩它一只在场；
2. 玩家背包仅剩余夜影狼一只精灵，无其他后备；
附加平衡限制：
① 只要场上存在存活队友 / 背包有其他精灵，特性全程白板，无任何攻防加成；
② 离场、阵亡清空翻倍buff，再次上场需要重新满足触发条件；
③ 仅提升双攻面板，速度、双防、血量、能量、免控、续航无任何额外增益；
④ 数值翻倍为基础面板放大，不和招式威力倍率多层叠乘，伤害不会恶性膨胀。

## 五、灵+地 属性攻防
进攻双倍克制：火、电、岩、草、超能
防御双倍致命弱点：水、飞行、妖精
属性抵抗：毒、虫、电

## 六、配招不变
1. 幽岩碎爪（地系物攻130，核心输出）
2. 怨灵突咬（灵系物攻125，补盲打击草、超能）
3. 土影潜行（干扰，降低敌方1级命中，常态苟活等残局）
4. 地层自愈（回合末回复9%最大生命值，小额续航兜底）

# 重点：触发特性后的完整强度评价
## 1、成型输出强度（实打实T0级别）
常态物攻140，翻倍后物攻等效280，搭配130威力本系地招、125灵系招式，斩杀线极其夸张：
- 绝大多数无物防强化的肉盾两回合内必定被击杀；
- 高速脆皮、输出精灵直接一招秒杀；
- 灵+地双属性打击面覆盖五大主流属性，几乎不存在完全打不动的目标，残局1穿2、1穿3能力无解。
速度123高速加持，成型后全程先手，对手很难有机会集火反打。

## 2、本次面板加强带来的成型生存提升
物防110，翻倍成型后面对物理输出容错大幅提高：
火、电、岩石这类物理系克制目标的攻击很难快速压低血量，能多输出1~2回合；
短板保留：魔防仅90，水系、妖精特攻双倍伤害依旧能快速打残，法系爆发是稳定突破口。

## 3、特性机制优化带来的强度变化（对比旧版）
旧版：需要站场等到队友死光才会慢慢触发；
新版：**满足条件上场直接自带翻倍**，不用空场苟回合，残局切换出场就能立刻拥有满额爆发，收割节奏更快，逆风翻盘能力更强，上限小幅抬高。

## 4、多重硬性枷锁，不会变成全局无解超模
### 制衡1：触发条件门槛极高，正常对局很难主动利用
想要稳定触发T0加成，两种苛刻条件：全队死光 / 背包只剩它一只。
常规推图、天梯组队对战，玩家不会主动清空全队精灵换取单只强化，90%对局全程白板，只有极限逆风残局才能解锁T0强度，无法作为常规首发核心。

### 制衡2：三大双倍弱点全程生效，成型后依旧存在稳定天敌
水系、飞行、妖精环境高频，大量同速度/超速特攻打手，双倍特攻伤害无视高额物攻面板，两回合就能击杀成型夜影狼；哪怕物防提升，法系短板无法弥补。

### 制衡3：无任何辅助生存增益，仅有攻击翻倍
特性只加双攻，不给免控、减伤、提速、大额回血；一旦被催眠、混乱、束缚控住，没有任何兜底手段，极易断输出节奏暴毙。

### 制衡4：buff离场直接清空，无法运营拉扯
残血切走后翻倍效果直接消失，再次上场必须重新满足“无队友存活”条件，不能提前叠好加成换场收割，战术容错很低。

### 制衡5：稀有度限制出场率
3小时仅刷新1只、捕捉难度高，玩家很难人手多只，不会造成环境全员携带夜影狼内卷失衡。

# 常态（未触发特性）强度定位
标准T1高速物攻手，物攻140、物防110综合素质不错，但无任何爆发增幅，常规组队推图有来有回，被水/飞/妖精稳定克制，不存在碾压环境的能力。

# 综合总结
1. 改动全部落地：物攻140、物防110、魔防90；特性修改为场上队友全阵亡/背包只剩自身时，上场直接双攻+100%；
2. 触发成型后确认为**标准T0残局霸主**，高额翻倍物攻+高速+优秀物理耐久，逆风收割能力顶尖；
3. 触发门槛、属性弱点、无生存加成、buff离场清零、稀有度五层制衡牢牢锁住泛用性，仅残局强、常规对局偏弱，不会破坏整体环境平衡；
4. 设定贴合孤狼孤身作战的人设，机制逻辑通顺，梯度分层清晰，可直接定稿。
