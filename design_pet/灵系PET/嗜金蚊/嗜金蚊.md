# 嗜金蚊 优化终稿（灵系、两段进化调整，速度98、魔攻128，新手村T2烦人小怪，不超模）
## 一、基础档案
名称：嗜金蚊
属性：纯灵系
生态：林间滋生的怨灵蚊虫，体内附着金属微粒，贪恋玩家身上金属饰品与防具；新手村高频刷新，成群出现非常折磨人。
进化链：金纹虫卵（一阶）→ 嗜金蚊（二阶最终形态）
定位：中速骚扰型魔攻小怪，前期难缠，中后期完全乏力，标准T2梯队，无破坏平衡风险
硬性调整：属性改为灵系、一阶为蠕动虫卵，速度下调98，魔攻上调128，特性保留不变

## 二、定型种族值
精力98 / 物攻62 / 魔攻108 / 物防75 / 魔防78 / 速度78
种族总和：98+62+108+75+78+98 = 499
### 面板拆解
1. 魔攻上调至128，基础法术伤害提升，新手低速精灵更容易被压低血量，强化“烦人”定位；速度下调98，不再顶尖高速，中后期大量100+速精灵可稳定先手反制；
2. 血量98、双防75/78全程脆皮，无耐久兜底，被克制属性招式命中直接残血；物攻彻底废弃，纯魔攻输出；
3. 纯灵系固定双倍弱点：地、火，新手村铁甲盔（地系）、各类火系野怪天然克制，完美锁死强度上限。
小怪固定努力分配：252魔攻、252速度、6精力
性格：急躁（+速度-物防）

## 三、两段外观
1. 一阶·金纹虫卵：半透明金色蠕动虫卵，成堆藏在草丛、金属碎石堆里，靠体表金属碎屑蠕动撞击玩家造成小额伤害，移动缓慢、威胁偏低；虫卵破裂后进化为成蚊。
2. 二阶·嗜金蚊：巴掌大小灵体蚊虫，半透明泛鎏金光斑，翅膀飘细碎金尘；悬浮空中高速盘旋俯冲，口针凝聚灵能金属脉冲远程攻击，会主动追着携带金属装备的玩家成群围堵。

## 四、专属特性【汲金自愈】（完全保留原版规则）
敌方释放**金系攻击技能**命中自身时：
1. 结算受到伤害数值，自身回复 该伤害÷2 等量生命值；
2. 仅敌方金系招式触发，自身、其他属性攻击无法触发回血；
3. 真实伤害、灼烧、毒素持续扣血不触发回血；
4. 离场、阵亡清空所有续航判定，无常驻回血buff。
### 制衡枷锁（牢牢锁定T2，杜绝超模）
1. 触发条件极窄，仅敌方金系伤害生效
主流精灵、新手初始宠多为火、地、草，极少携带金系招式，90%对局特性等于白板，无续航加成。
2. 回血收益对半折，续航能力微弱
单次受到100金伤仅回50血，自身血量上限仅98，两次金系攻击即可直接清空血量，无法永动拉扯。
3. 双重主流双倍弱点：地、火
新手村铁甲盔（地系）、火焰类小怪随处可见，双倍伤害能无视小额回血，一套爆发直接秒杀，稳定封锁发挥空间。
4. 速度98中低速，中后期高速精灵全覆盖
藤蔓蛇、辣椒武者速度110，稳定先手打出克制伤害，根本不给嗜金蚊触发特性、持续骚扰的机会。
5. 无增伤、无控场、无护盾自保手段
仅靠基础灵系输出，面对高双防肉盾全程刮痧，仅能欺负前期无成型精灵的新手。

## 五、纯灵系属性攻防

## 七、全方位强度评价（是否超模）
### 前置结论：完全不超模，标准T2新手专属烦人小怪，前中期有压制力，中后期彻底作废
### 一、本次优化改动带来的变化
1. 属性更换灵系，匹配森林灵蚊世界观，和地灵双属性铁甲盔形成地图属性联动，剧情生态统一；
2. 一阶改为蠕动虫卵，丰富小怪阶段机制，草丛埋伏偷袭提升烦人程度；
3. 魔攻提升128小幅提高前期伤害，速度下调98削弱后期先手优势，做到前期恶心、后期弱势；
4. 保留汲金自愈特色内战续航，成群金系互殴时拉扯感更强，贴合“蚊子难缠”设定。

### 二、多层不可消除短板，杜绝无解强度
1. 特性触发门槛苛刻，泛用性极低
只要对手不使用金系技能，完全没有回血能力，只是脆皮低速输出，无任何战术价值；
2. 双重致命弱点遍布全地图，克制单位随处可见
地面、火系是开荒、对战通用强势属性，随便一只对应精灵就能稳定秒杀，不存在翻盘能力；
3. 身板脆弱无常驻续航，无法长期站场
仅靠特性小额回血，无护盾、无回合回血，多段克制伤害下血量下滑极快；
4. 输出单一打击面窄，仅克制草、超能，对地、火、金属性全部刮痧；
5. 速度劣势中后期暴露，高速精灵全程先手压制，很难持续骚扰。

### 三、分场景精准定位
1. PVE新手村：T2恶心骚扰小怪
新手仅有草、水系低速精灵时，成群嗜金蚊降命中+小额回血拉扯，战斗拖沓烦躁；解锁地/火系精灵后可一键清场，瞬间失去威胁。
2. 中后期PVE/PVP：下水道T2废件
高速火、地精灵普及，几乎没有上场空间，特性很难触发，输出刮痧、身板脆弱，无法编入作战队伍。

## 八、综合总结
1. 完整落实所有优化需求：灵系精灵、一阶蠕动虫卵、二阶飞行蚊虫，速度98、魔攻128，特性汲金自愈不变；
2. 小幅拉高前期输出强化烦人定位，同步下调速度、保留双重弱点限制后期强度，多层制衡完整锁死T2梯队；
3. 和森林铁甲盔、辣椒武者地图属性体系联动，梯度分层清晰，不会干扰主线强力精灵平衡，可直接定稿使用。
