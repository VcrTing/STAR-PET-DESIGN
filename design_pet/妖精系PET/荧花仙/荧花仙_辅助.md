# 萤花仙 完整定稿（草+妖精｜低速团队回能辅助）
## 一、基础设定
1. 属性：草 + 妖精
2. 栖息点位：新手村森林中央花海空心古树，与赤红焰蛹（六翼火蝶）枯木区域相邻，定点可捕捉
3. 定位：低速全队续航辅助，轻度魔攻补伤，专为萌新缓解全队技能能耗压力

## 二、三段进化外观
1. 一阶：萤花籽（捕捉初始形态）
圆滚滚嫩绿花苞精灵，外层裹半透明荧光花瓣小翅，周身缠绕细嫩草藤，头顶一朵小白野花；根系浅浅扎进林间腐土，蹦跳行动，外形软萌无攻击性，草木与仙灵质感结合。
2. 二阶：萤瓣草仙
体型放大一圈，四片花瓣羽翼完全舒展，藤蔓顺着躯干缠绕生长，周身飘散青草荧光孢子，走动会落下细碎治愈光粉。
3. 终形态：萤花仙
纤细仙灵体态，六片粉绿渐变花瓣翅膀；发丝由开花藤蔓编织而成，裙摆铺满青苔与嫩草；脚下会自然生成青草场地，草木柔光环绕，同时兼具草本生机与妖精仙气。

## 三、最终定型种族值（按要求调整：速度40、魔攻110）
精力108 / 物攻30 / 魔攻110 / 物防82 / 魔防112 / 速度40
种族总和：482
### 数值说明
1. 物攻30完全作废，放弃物理输出，纯魔攻辅助定位；
2. 魔攻下调至110，仅用来补刀克制目标，无高额斩杀爆发；
3. 速度40极低速，对局永远后手，无法先手铺场地、开防控、抬血，极易被高速克制宠先手压制；
4. 魔防112法系抗性优秀，妖精免疫龙系伤害，草属性抵抗水、土、电；物防仅82，物理输出极易压低血量，天然生存短板。
### 培育推荐
性格：保守（+魔攻-物攻）
努力值分配：魔攻252、精力252，剩余6点魔防

## 四、专属特性：繁花共生
完整效果：
自身存活在场期间，**每回合战斗结算结束，己方所有存活精灵（包含自身）全部技能PP值+1，PP不会超过技能上限，最低不低于0**。
配套平衡规则：
1. 自身被切换下场、阵亡，回能效果立刻终止；
2. 陷入睡眠、冰冻、恐惧等控制异常，不会中断每回合全队回能；
3. 仅对己方生效，无法为敌方恢复技能能耗。

### 特性平衡约束（速度40+面板短板对冲强势回能）
全队同步回PP机制单独看强度很高，但多重限制锁住上限：
1. 永久后手，敌方高速火、金、冰、灵克制宠可先手爆发，直接击杀萤花仙，全队续航直接中断；
2. 草+妖精四重弱点：火、冰、金、灵双倍克制，物防偏低，很难长时间站场维持回能；
3. 魔攻仅110无输出压制力，无法快速清场，只能依靠队友打伤害，自身无单带能力。

## 五、草+妖精 属性攻防（沿用11属性克制规则）
### 进攻克制叠加
草克制：水、土；妖精克制：龙、斗
专门针对中期山地斗系、雪山龙系、前期水土野怪，补全队伍克制缺口。
### 防御弱点（四重双倍克制，强力制衡）
草弱点：火、冰；妖精弱点：金、灵
弱点合计：火、冰、金、灵，四类属性均有大量高速输出精灵，专门针对克制萤花仙。
### 防御抵抗&免疫
草抵抗：水、土、电；妖精抵抗：斗；妖精自带**免疫龙系**伤害
完美弥补新手村队伍弱电、无龙免疫的两大生存缺陷。

## 六、萌新极简配招（无复杂联动，操作门槛低）
1. 仙藤荧光（草+妖精双系魔攻 威力125 唯一输出技能）
享受草、妖精双本系加成，克制水、土、龙、斗四类怪物。
2. 繁花滋养（变化技能）
为全队回复13%最大生命值，长线开荒、BOSS战续航核心。
3. 青草结界（场地技能，持续5回合）
场上存在青草场地时，全队草系技能威力提升15点，搭配回能反复持续铺场。
4. 花雾免控（防控变化，持续3回合）
免疫所有控制异常，低速后手只能挨打后开出自保，容错有限。

## 七、场景强度定位
1. PVE新手开荒/长线高难BOSS：T1上游顶级辅助
AI不会针对性集火，萤花仙可安稳站场持续全队回PP，多宠轮换打持久战零能耗焦虑，开荒体验大幅提升。
2. PVP天梯对战：T2娱乐功能辅助
极低速+四重弱点，极易被高速克制宠快速击杀，续航体系难以稳定维持；仅慢速消耗联防队可搭配使用，无法作为对战核心精灵。

## 八、整体总结
1. 完全遵照修改需求：草+妖精双属性、速度40、魔攻110、特性在场全队（含自身）每回合回复1点技能能耗；
2. 外观贴合森林花海生态，三段进化层次清晰，和新手村其他精灵画风统一；
3. 全队回能机制虽功能性极强，但极低速度、薄弱物防、四重属性弱点多重制衡，不会出现对战失衡；
4. 定位纯粹团队辅助，输出能力大幅削弱，侧重服务萌新组队推图，PVP有明确天敌与破解手段。
