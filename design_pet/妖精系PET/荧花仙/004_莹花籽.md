# 莹花籽 完整定稿（草+妖精｜二段进化一阶，图鉴编号4）
## 一、基础设定
0. 图鉴编号：4
1. 属性：草 + 妖精
2. 栖息点位：新手村森林中央花海空心古树，与赤红焰蛹（六翼火蝶）枯木区域相邻，定点可捕捉；仅白天阳光充足时段刷新
3. 整体定位：低速基础续航辅助，微弱魔攻补伤，萌新前期过渡辅助宠，为进化萤花仙铺垫机制认知
4. 身高区间：0.30m ~ 0.42m，体重区间：0.2kg ~ 0.6kg
5. 性情设定：温和温顺，**不会主动攻击人类与野生精灵**，遭遇危险顺着微风飘走躲避
6. 稀有度：普通可捕捉精灵，非限定、非BOSS
7. 进化规则：等级36级进化为图鉴5·萤花仙，全系列仅两段进化

## 二、外观
莹花籽为萤花仙前置进化形态，主体是圆润饱满的花草种子团子，整体低矮，习惯长期停靠陆地苔藓、花丛地面；头顶生长两片狭长嫩绿色叶片，是核心感知器官。
无风时安静趴在地面扎根，周身环绕微弱淡黄绿色萤火；起风后依靠轻薄种皮浮空低空缓慢飘荡，飞行高度不超过半米；移动全程持续摇晃头顶叶片感知气流与方位，确认安全后立刻落地停留，不会长时间浮空。
无成型花瓣翅膀、无藤蔓发丝，身形小巧敦实，没有浮空青草场地生成能力。

## 三、定型种族值（按要求下调数值）
精力56 / 物攻22 / 魔攻64 / 物防50 / 魔防60 / 速度32
种族总和：284
### 数值说明
1. 物攻22完全作废，无物理输出能力，纯魔攻辅助模板；
2. 魔攻下调至64，仅能打出极低的基础草系法术伤害，完全没有补刀斩杀能力；
3. 速度32极低速，全程后手，无法先手铺增益、抬血，极易被高速野怪先手压制；
4. 物防仅50、魔防60，双耐久大幅削弱，物理、法术伤害都能快速压低血量，生存短板被进一步放大。
### 培育推荐
性格：保守（+魔攻-物攻）
努力值分配：魔攻252、精力252，剩余6点魔防
个体值优先：精力、魔攻拉满，魔防随缘，物攻、物防无需培养

## 四、专属特性：繁花共生
完整效果：
自身存活在场期间，**每回合战斗结算结束，己方所有存活精灵（包含自身）全部技能PP值+1，PP不会超过技能上限，最低不低于0**。
配套平衡规则：
1. 自身被切换下场、阵亡，回能效果立刻终止；
2. 陷入睡眠、冰冻、恐惧等控制异常，不会中断每回合全队回能；
3. 仅对己方生效，无法为敌方恢复技能能耗。

### 特性平衡约束（低速+极低耐久对冲回能强度）
全队同步回PP功能性较强，但多重限制锁死前期强度：
1. 永久后手，敌方高速火、金、冰、灵野怪可先手压低血量甚至直接击杀，续航效果直接中断；
2. 草+妖精四重弱点：火、冰、金、灵双倍克制，双防数值极低，很难撑过敌方一轮输出，难以长时间站场持续回能；
3. 魔攻数值大幅降低，没有独立清图能力，完全依靠队友承担主要输出。

## 五、草+妖精 属性攻防（沿用11属性克制规则）
### 进攻克制叠加
草克制：水、土；妖精克制：龙、斗
适配新手森林水土野怪，提前补齐队伍克制短板，为中后期山地、雪山地图做准备。
### 防御弱点（四重双倍克制，强力制衡）
草弱点：火、冰；妖精弱点：金、灵
弱点合计：火、冰、金、灵，四类属性野外高速精灵数量多，天生克制莹花籽。
### 防御抵抗&免疫
草抵抗：水、土、电；妖精抵抗：斗；妖精自带**免疫龙系**伤害
提前弥补新手前期队伍弱电、无龙属性免疫的生存缺陷。

## 六、生态与抓捕规则
1. 刷新逻辑：森林花海地面大面积刷新，野外仅刷新莹花籽，无直接刷新萤花仙；
2. 抓捕道具：普通捕捉球即可稳定捕捉，新手开局就能获取对应道具；
3. 伴生精灵：常与天翊四叶（水+草）共同栖息花海地面，生态互补；
4. 行为特征：绝大多数时间趴在陆地苔藓上休息，风吹才低空飘移，头顶叶片不停晃动辨别方向，贴近后触发对战，不会主动进攻。

## 七、闪光异色设定
闪光莹花籽种皮为奶白浅青色，萤火泛银白色；
闪光个体区间微调：身高趋近区间上限0.42m，体重趋近区间下限0.2kg；基础速度小幅+4，仅36，依旧属于低速梯队，不改变核心短板。

## 八、场景强度定位
1. PVE新手开荒前期过渡：T2优质功能辅助
前期野外野怪输出较低，AI不会集火，莹花籽可短暂站场提供全队回PP，小幅减少新手频繁回城补技能能耗的麻烦。
2. PVP天梯对战：无上场价值
速度极低、双防薄弱、输出乏力，任意高速克制精灵都能一回合击倒，无法组建续航体系。

## 九、适配队伍搭配推荐
### 最佳搭档
1. 岩颅凶狼（地面物攻主线BOSS）：莹花籽补充地面系惧怕的水、草属性续航，龙系免疫完美保护狼人；
2. 雷蜂王（电系蜜蜂）：电属性克制莹花籽弱点冰、金属，二者克制链互补；
3. 森林金刚（山地草系主线BOSS）：双草系搭配延长站场回合，放大回能收益。
### 天敌精灵
火系、冰系、金属、灵系高速输出精灵，例如初期火焰野怪、雪山冰枭，先手爆发可快速击倒莹花籽，直接切断全队回能。

## 十、整体总结
1. 严格遵循设定需求：图鉴编号4、二段进化一阶、草+妖精属性、下调魔攻64/物防50/魔防60、低速面板、繁花共生回能特性；
2. 生态行为独特，以陆地栖息为主，随风低空飘荡、叶片辨向的形象辨识度高，和终形态萤花仙进化逻辑连贯统一；
3. 全队回能机制实用，但极低速度、大幅削弱的双防、四重属性多重弱点严格限制强度，前期不会破坏游戏平衡；
4. 定位新手过渡型辅助，输出能力薄弱，核心作用是解决前期刷图技能PP不足问题，进化后萤花仙双防、魔攻全面提升，强度完整升级。
