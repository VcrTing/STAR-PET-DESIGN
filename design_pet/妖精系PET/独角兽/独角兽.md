# 灵汐独角兽 最终整合定稿（调整后种族，特性完全不变）
## 一、基础档案
名称：灵汐独角兽
属性：纯妖精
定位：辅助兼魔攻手，单打稳定T1，搭配体系辅助可冲到T0
速度：92
美术风格：轻奢儿童向，通体雪白、渐变天蓝色鬃毛，圣洁柔和无尖锐造型，单形态高阶精灵，月光花海、圣林浅滩限定捕捉

## 二、外形设定
1. 身躯雪白流线型，线条圆润柔和；蓬松鬃毛由白渐变天蓝，行动自带微光
2. 独角莹白通透，萦绕淡蓝光晕，蹄尖染浅蓝柔光
3. 常驻微弱圣洁光晕，栖息花海与静水岸边，性情温顺，仅队友遇险才会参战庇护
4. 无狰狞棱角，整体干净治愈，贴合“不染污浊”的特性人设

## 三、调整后种族值
精力105 / 物攻82 / 魔攻138 / 物防80 / 魔防105 / 速度92
总和：602
面板解析：
1. 精力下调至105、物防降至80，耐久小幅削弱，降低单人站场强度，避免单打超模
2. 速度上调至92，小幅提升出手权，能更稳定先手释放回血、防御buff
3. 魔攻138保留不变，输出能力完整保留，兼顾辅助与输出
4. 物攻82无作用，彻底放弃物理输出路线

## 四、专属特性【净世之躯】（无改动）
完整效果：
1. 自身免疫全部异常状态：中毒、剧毒、麻痹、烧伤、睡眠、冰冻、混乱、魅惑、诅咒全部无效
2. 自身能力等级不会被敌方降低，免疫降攻、降防、降速类干扰

机制价值：
单打依靠免控稳定输出；组队作为体系核心挂件，不会被控断节奏，搭配强攻、肉盾精灵直接成型T0阵容，机制长期保值。

## 五、属性攻防克制
### 进攻双倍克制
格斗、龙、恶
### 防守双倍弱点
毒、钢（核心制衡点，克制自身高魔防）
### 防守抵抗
虫、格斗

平衡短板：
耐久下调后更容易被高速毒/钢精灵先手击杀；速度92依旧低于100高速梯队，存在稳定反制手段，无无解对局。

## 六、标准对战配招（辅助输出两用）
1. 天辉灵角（妖精·特攻130，本系核心爆发）
2. 星尘低语（妖精·特攻100，命中降低敌方特攻1级）
3. 清辉祈愈（变化，全队恢复15%最大生命值）
4. 月羽屏障（变化，全体队友物防提升1级）

## 七、强度分层评价
1. 单打PVE/PVP：标准T1
耐久削弱后单人续航下滑，缺少全队增伤，无法单人无脑推队，强度适中不超标
2. 组队体系PVP：准T0核心挂件
稳定免控加成，搭配鱼龙王、流云长龙等强攻精灵，大幅拉高队伍容错，成型后压制力极强
3. 长期保值：全异常免疫属于对战刚需机制，环境更迭永远有出场空间

## 八、生态与获取
出没地点：云端花海、月光圣林浅滩

习性：天性避战，仅队友受重创时释放圣光进行庇护
