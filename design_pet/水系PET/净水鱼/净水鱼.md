# 净水鱼 完整优化定稿（双形态·无限叠层减能耗·纯收藏玩具定位，多重制衡绝不超模）
## 一、基础设定
1. 属性：纯水系，栖息新手村溪流深沟，和熔岩鱼同水域捕捉
2. 两段形态：幼体「细流小鱼」→ 完全体**净水鱼**（最终形态定名）
3. 定位：纯图鉴玩具、水系娱乐挂件，无实战上分能力，仅多水系娱乐队整活使用
4. 固定种族值（严格按你要求，全面压低输出面板）
精力98 / 物攻70 / 魔攻100 / 物防75 / 魔防78 / 速度70
种族总和：98+70+100+75+78+80 = **491**
### 数值制衡说明（从根源锁死强度）
1. 魔攻仅100，属于全游戏下游输出面板，哪怕无限减能耗高频放技能，基础伤害极低，无法斩杀常规精灵；
2. 双防75/78、生命98身板极脆，水系弱点草、电双倍克制，高速电/草宠两轮直接秒杀，站场叠层时间极短；
3. 速度80中低速，天梯主流高速输出永远先手压制，极易被控、被爆发压残；
4. 物攻70完全作废，纯魔攻单路线，打击面只有火、土，面对龙/灵/金/斗全程刮痧。
培育推荐：保守（+魔攻-物攻），努力魔攻252、精力252，剩余6魔防（即便拉满输出依旧疲软）

## 二、两段形态外观
1. 一阶·细流小鱼（捕捉初始形态）
小巧透明淡蓝小鱼，鱼身萦绕细碎净水微光，尾鳍轻薄如水波纹；常年躲浅滩净水过滤杂质，体型柔弱，幼体特性叠层收益减半，前期完全没法整活。
2. 二阶·净水鱼（最终大鱼形态）
体型舒展的琉璃净水大鱼，通体通透水蓝色，背鳍、尾鳍层层流水纹路，周身漂浮净化水雾；游动会净化水域杂质，造型柔和无攻击性，主打收藏观赏。

## 三、专属特性【净流共生】（允许无限叠层，叠加五层硬性枷锁控制强度）
### 完整效果（仅进化净水鱼解锁满效果，小鱼削弱）
己方场上**每存活1只水系精灵**，净水鱼自身水系威力技能能耗永久-1，层数无上限、可无限叠加；
#### 五层核心平衡限制（彻底杜绝无限0能耗乱杀，贴合玩具定位）
1. **收益仅限自身水系输出技能**
护盾、净化、防控、减益等变化技能完全不享受减耗，只能省攻击技能能耗，没法无限开免控、群体续航；
2. **必须自身在场存活才统计层数，离场/阵亡所有叠层直接清零**
换宠、被击杀后叠层全部重置，下次上场需要重新凑水系队友重新叠，无法离场留存高额减耗；
3. **低基础魔攻兜底，叠满减耗也无伤害**
就算凑6水系全队叠5层减耗，大招随便甩，但魔攻100基础伤害极低，打高双防肉盾几乎不掉血，仅能清理低血量小怪；
4. **成型门槛极高，常规队伍完全无法触发高叠层**
标准对战队伍只会携带1~2只水系，最多减1~2能耗，提升微乎其微；必须刻意组全水系娱乐队才能叠高层，常规天梯、开荒阵容根本发挥不出特性；
5. **幼体小鱼强制削弱**
细流小鱼每层仅减0.5能耗，向下取整，全场最多减1点，前期开荒没有任何整活空间，不会破坏新手平衡。

### 叠层实战举例
6水系全队在场，大招基础7PP，7-5=2消耗，释放频率提升，但魔攻100输出刮痧；
常规1水系队伍，大招7-1=6消耗，几乎没有手感提升。
