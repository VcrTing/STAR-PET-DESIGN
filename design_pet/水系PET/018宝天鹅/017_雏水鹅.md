# 雏水鹅 完整完善定稿（纯水｜宝天鹅一阶初始形态，图鉴017）
## 一、基础设定
0. 图鉴编号：017
1. 属性：纯水
2. 栖息点位：全地图湖泊、平缓浅水滩，与池云鲤、小枯树干同水域刷新，宝天鹅的初始进化形态
3. 整体定位：低速前期过渡功能辅助，和二阶宝天鹅共享【净水封印】同款清印记特性，基础面板全面削弱，实战收益微薄，强度T3，40级进化图鉴018宝天鹅
4. 体型尺寸：幼年迷你天鹅体态，身形小巧圆润，站立高度仅到成年人膝盖上方一点点，体型远小于成体宝天鹅
5. 身高区间：0.32m ~ 0.40m，体重区间：24kg ~ 33kg
6. 性情设定：胆小温顺，完全不会主动攻击人类，整日成群在浅滩水面自在浮游，无视岸边行人，只有被主动触碰时才会被迫应战
7. 稀有度：水域基础野生精灵，刷新数量庞大，普通捕捉球即可百分百捕获，无稀有限定、无BOSS
8. 进化规则：等级40级稳定进化为图鉴018·宝天鹅，两段进化链：雏水鹅→宝天鹅
9. 战斗行为：浮在浅水面小型周旋，依靠幼嫩羽翼水流斩、微弱水珠吐息输出；水系招式命中可清除敌方单类印记，但自身血量、耐久极低，很难持续站场反复触发净化效果

## 二、外观
一阶形态：雏水鹅
通体短绒奶白色幼鹅，羽翼短小蓬松，表层仅有极淡细碎水光，没有成体修长顺滑的羽毛；脖颈短粗，胸口仅有一枚极小淡蓝色水珠雏形，未形成成型水宝珠。
身形矮小，仅到膝盖上方，游动时姿态笨拙稚嫩，静止漂浮水面可伪装普通小野鸭；释放净化时仅胸口微光闪烁，无大范围蓝光水雾特效。
和宝天鹅区分点：无修长身形、无饱满水光羽翼、无大型水系宝珠，整体幼态感十足。

## 三、定型种族值（总值精准控制298）
精力82 / 物攻48 / 魔攻52 / 物防46 / 魔防60 / 速度30
种族总和：318
### 数值说明
1. 魔攻52略高于物攻48，继承法术为主的输出模板，但整体伤害刮痧，仅能清理开局最低等级野怪；
2. 速度30极低速梯队，绝大多数前期精灵速度更高，极易被先手压制，很难稳定出手触发清印记特性；
3. 魔防60为唯一小幅突出的耐久，物防46、精力62全面偏低，草、电双倍克制伤害能轻易将其打至残血；
4. 总种族值298，标准新手杂鱼面板，坦度、输出、功能性全部拉胯，仅前期临时过渡使用。
### 性格推荐
保守（+魔防-物攻）
### 天赋推荐
魔防、精力、魔攻三项核心天赋拉满极品，物攻、物防、速度无需培养

## 四、专属特性：净水封印（机制和宝天鹅完全一致）
完整效果：
自身任意水系招式命中敌方单位后，直接清空目标身上**同一类型所有叠加印记**（龙云印记、瀚海聚能层数、奇甲固守加成层等全部归类对应印记体系，单次命中清除单目标一类全部层数）；
配套平衡规则：
1. 单次水系攻击仅可清除单一目标一类印记，无法一次性清空全场多单位、多类型印记；
2. 印记清除无冷却限制，只要水系招式持续命中，可反复清除敌方重新叠加的印记；
3. 被控（睡眠/冰冻/恐惧）状态下水系招式依旧可以正常触发清印记效果，控制无法封锁核心辅助能力；
4. 仅清除敌方叠加增益印记，无法消除我方自身buff、场地效果、属性增减益。

### 特性平衡约束（极低面板锁死强度，特性机制完整但实战作用微弱）
虽和成体宝天鹅拥有一模一样的清印记机制，但全方位薄弱的基础面板牢牢限制强度，不会破坏前期数值平衡：
1. 血量偏低、物防薄弱，草、电高速克制精灵先手双倍伤害，经常没来得及释放水系净化招式就被直接秒杀；
2. 速度仅有30，永远后手挨打，敌方可以轻松叠满高额印记爆发后，雏水鹅才有机会出手净化，无法提前阻断输出；
3. 输出能力极低，就算清除敌方印记，也没有足够伤害快速压低对手血量，单宠作战几乎没有作用，必须搭配强力队友才能勉强发挥一点功能。

### 防御抵抗&免疫
水抵抗：草、电；无属性免疫

## 六、生态与抓捕规则
1. 刷新逻辑：全地图浅滩、湖边海量刷新雏水鹅，野外无法直接捕捉宝天鹅；
2. 抓捕道具：普通捕捉球稳定捕获，玩家初次抵达湖泊水域即可获取；
3. 伴生精灵：成群结伴浮游水面，常和池云鲤、小枯树干混居；
4. 行为特征：整日安静漂浮水面，无视路过人类，不会主动靠近挑衅，只有玩家主动触碰才会进入对战。

血量、双防、输出全面拉胯，极易被草、电高速精灵秒杀，无法组建克制叠层体系。

## 十、整体总结
1. 完全匹配设定需求：图鉴017一阶幼年雏水鹅，身高到膝盖上方一点，40级进化宝天鹅，纯水属性，种族总值精准298，净水封印特性机制完全和成体一致；幼年迷你天鹅外形、温顺浮游不攻击人类的生态设定全部保留；
2. 稚嫩幼鹅形象和修长华丽的成体宝天鹅体型、外观反差巨大，两段进化成长梯度清晰，水域精灵生态连贯统一；
3. 同款克制叠层的核心特性，但极低种族值、极低速、双重属性弱点多重制衡，前期强度可控，不会出现数值超模问题；
4. 定位仅为湖边前期过渡杂鱼，净化辅助功能实战收益极低，必须进化为宝天鹅才能发挥完整清印记战术价值，无天梯对战使用空间。
