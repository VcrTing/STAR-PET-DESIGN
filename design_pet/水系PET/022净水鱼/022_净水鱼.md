# 净水鱼 完整优化定稿（双形态·纯收藏玩具定位，多重制衡绝不超模）
## 一、基础设定
0. 图鉴编号：022
1. 名称：净水鱼
2. 属性：纯水系
3. 栖息点位：新手村山间溪流深水沟，与熔岩鱼共享同一片水域，深浅暗流区域均可刷新
4. 体型尺寸：成体净水鱼体长仅到成年人大腿位置，身形纤细柔和
体长区间：0.60m ~ 0.72m，体重区间：18kg ~ 26kg
5. 性情设定：天性胆小怯生，察觉到人类靠近会主动后退一米保持安全距离，不会主动发起攻击，仅玩家主动触碰才会强制进入对战
6. 进化链：两段完整进化，一阶细小鱼 28级进化 → 二阶净水鱼（最终形态）
7. 战斗定位：水系娱乐型魔攻手，纯图鉴收藏观赏宠，无天梯上分能力，仅多水系娱乐整活队伍使用
8. 定型种族值
精力98 / 物攻60 / 魔攻120 / 物防75 / 魔防78 / 速度69
种族总和：98+60+120+75+78+69 = 490
### 数值解析
1. 魔攻110为核心输出面板，定位魔攻手，但整体数值偏低，缺少高额斩杀爆发；物攻70数值低迷，完全不作为输出手段；
2. 速度69低速档位，绝大多数主流精灵速度更高，容易被先手压制，难以稳定输出；
3. 精力98、物防75、魔防78三项耐久全部偏低，站场承伤能力薄弱，无法持续作战；
4. 总种族值490，远低于主流对战精灵600左右标准，从数值层面锁死对战强度，贴合收藏娱乐定位。
### 推荐性格
保守（+魔攻-物攻）、稳重（+魔防-物攻）
### 天赋选择
魔攻、精力、魔防三项核心天赋拉满极品，物攻、速度、物防无需刻意追求满天赋

## 二、两段形态外观
### 二阶·净水鱼（最终形态）
体型舒展的琉璃质感大鱼，通体通透淡水蓝色，鱼身自带波光流转的通透肌理；背鳍、尾鳍分层布满流动水纹纹路，游动时周身持续漂浮稀薄净化水雾，途经水域会自动净化淤泥杂质。整体线条圆润柔和，无尖刺、獠牙等攻击性造型，设计核心偏向观赏收藏。

### 一阶·细小鱼（进化前置幼体）
体型迷你半透明鱼苗，体长仅成年人小臂长短，体色浅淡天蓝，鱼鳍单薄光滑，没有净水鱼专属流水纹路，仅尾部萦绕极淡水光；习性同样惧怕人类，栖息溪流浅滩，等级达到28级即可进化为净水鱼。

## 三、专属特性【雨净祛厄】
完整效果：
战场天气为下雨时，自身登场瞬间、每回合行动结束自动清除自身全部异常状态（中毒、剧毒、睡眠、冰冻、恐惧、灼伤等所有负面debuff全部清空）。
### 特性平衡约束
1. 效果高度绑定雨天天气，无雨天环境时特性完全失效，自身没有任何解控自保手段；
2. 仅作用于自身，无法为队友清除异常，不存在团队辅助价值；
3. 自身耐久、输出面板整体薄弱，即便解除异常，也扛不住草、电双倍克制伤害，无法依靠特性完成翻盘；
4. 无增伤、减能耗、提速、叠防御等增益效果，功能单一，对战上限极低。

## 四、纯水属性攻防（沿用专属11属性克制倍率表）
### 进攻克制
水系克制火、土；抵抗草、电
仅能稳定克制地图火系、土系野怪，对战草、电属性精灵输出会被压制。
### 防御弱点
双倍弱点：草、电，新手溪流区域随处可见两类属性精灵，是核心制衡短板。
### 防御抵抗：草、电，无任何属性免疫

## 五、生态与捕捉规则
1. 刷新分布：溪流深浅沟全天持续刷新，一阶细小鱼刷新数量庞大，二阶净水鱼低概率直接野外刷新；与熔岩鱼同水域交替出现；
2. 抓捕道具：普通捕捉球即可稳定捕获，玩家解锁新手村溪流区域后就能批量获取；
3. 行为特征：日常在水底缓慢巡游，主动净化水底淤泥杂质；感知人类靠近立刻后退一米保持距离，全程不会主动开战。

## 六、闪光异色设定
闪光净水鱼通体为浅青琉璃色，周身水雾替换为淡银白色，鱼鳍流水纹路泛浅紫微光；体型、体重区间不变，种族数值无任何强化。

## 七、场景强度定位
1. PVE开荒：T3娱乐杂鱼
仅雨天场景能小幅发挥解控效果，其余环境下对战表现全面弱势，推图优先级远低于萤花仙、宝天鹅等功能型精灵；
2. PVP天梯对战：无上场价值
总种族偏低、特性绑定专属天气、双重属性弱点，成型竞技队伍不会携带，仅休闲娱乐水系整活队伍使用。

## 八、整体总结
1. 完全贴合全部设定需求：图鉴020纯水净水鱼，28级由细小鱼进化，体长至人类大腿，胆小见人后退一米；固定490种族总值、雨天解控特性、收藏玩具定位完整保留；
2. 幼体小鱼和成体琉璃大鱼外形差异明显，两段进化成长梯度清晰，溪流水系观赏向精灵画风统一；
3. 特性功能单一且依赖天气，搭配偏低种族值、草电双重克制弱点多重制衡，不存在超模碾压对局；
4. 定位纯收藏观赏宠，仅适合休闲水系娱乐队伍，无竞技上分潜力，数值与机制平衡合理。
