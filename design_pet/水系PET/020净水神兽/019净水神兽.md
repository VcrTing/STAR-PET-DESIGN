# 水纹兽 完整定稿（纯水｜净水神兽一阶前置形态，图鉴019）
## 一、基础设定
0. 图鉴编号：019
1. 名称：水纹兽
2. 属性：纯水系
3. 栖息点位：全大陆溪流、湖泊、浅滩全域随机刷新，无地图限制，雨天刷新概率小幅提升，净水神兽唯一进化前置
4. 体型尺寸：迷你豹型幼兽，整体身高仅到人类膝盖高度
身高区间：0.45m ~ 0.55m，体重区间：22kg ~ 30kg
5. 性情设定：性格温顺亲人，不会主动攻击人类，喜欢跟随行人周身的水雾缓慢跑动，见到沾染污浊、负面气息的野怪会主动靠近释放微弱水流净化
6. 稀有度：普通野生精灵，刷新量中等，中级捕捉球稳定捕获，无传说限定标签
7. 进化规则：等级达到50级，且战场处于雨天天气时，触发净化进化，化为传说神兽净水神兽
8. 战斗定位：前期过渡均衡双刀杂鱼，完整继承特性【净羽升华】，面板全面大幅削弱，实战收益极低，强度T4
9. 定型种族值（总值严格控制270）
精力58 / 物攻17 / 魔攻77 / 物防43 / 魔防43 / 速度42
种族总和：58+17+77+43+43+42 = 280
### 数值解析
1. 物攻、魔攻数值完全持平，延续双刀均衡模板，但双攻数值极低，无斩杀输出能力，仅能清理新手低等级小怪；
2. 速度42低速梯队，绝大多数精灵可先手压制，很难提前触发特性转化减益；
3. 精力、双防全部偏低，耐久单薄，草、电双倍克制伤害命中直接残血，无法持续站场；
4. 总种族270，属于入门杂鱼标准数值，和净水神兽706神兽面板形成断层式强度差距，合理区分普通精灵与传说神兽。
### 推荐性格
急躁（+速度-物防）、天真（+速度-魔防）
### 天赋选择
物攻、魔攻、速度拉满极品，精力、双防无需重点培养

## 二、外观设定
一阶形态：水纹兽
小巧幼豹体态，四肢短细，身形没有净水神兽猎豹般流畅修长的流线肌肉；通体浅淡半透明水蓝色短绒毛，体表只有零散细碎浅淡水纹，无大面积琉璃水光；头顶只有一对短小圆润的水晶幼角，不会持续滴落净化清水；周身仅萦绕一丝几乎看不见的薄雾，不具备大范围净化强光特效。
整体娇小软萌，体型贴合膝盖高度，跑动姿态笨拙稚嫩；仅在雨天周身微光会轻微变亮，满足50级雨天条件后完成蜕变，进化为琉璃质感的净水神鹿。
和净水神兽核心区分：体型矮小、无修长猎豹体态、鹿角短小、水雾特效微弱、无通透琉璃肌理。

## 三、专属特性【净羽升华】（机制与净水神兽完全一致）
完整机制规则：
1. 转化效果：自身身上所有属性降低类减益效果，全部等额反向转化为对应属性增益
例：物攻降低30 → 物攻提升30；速度降低20 → 速度提升20；物防、魔防、魔攻减益全部同步反转加成；
2. buff留存规则：自身主动切换离场时，当前所有转化得到的等额增益完整保留；若自身被敌方击杀阵亡，全部转化增益直接清空，无法传递给下一只精灵；
3. 生效范围：仅针对自身属性增减益，无法反转敌方减益、无法清除印记类debuff，仅作用攻防速四维属性数值变化；
4. 控制状态不封锁特性：陷入睡眠、冰冻、恐惧等控制时，新获得的属性减益依旧会实时反转成增益。
### 特性平衡约束（极低面板锁死实战强度）
虽然继承神兽同款核心特性，但全方位短板限制实战发挥，不会破坏前期数值平衡：
1. 自身双攻、耐久全部偏低，即便成功转化减益获得加成，输出与承伤能力依旧疲软，难以完成击杀；
2. 低速短板明显，敌方草、电克制精灵可先手打出高额伤害，经常来不及转化减益就被直接击倒；
3. 无主动给自己施加减益的手段，必须依靠敌方削弱才能触发收益，无debuff时特性完全无效；
4. 无团队辅助能力，仅自身单目标生效，没有队伍增益价值。

## 四、纯水属性攻防（沿用专属11属性克制倍率表）
### 进攻克制
水系克制火、土；抵抗草、电
仅能清理新手区域低等级火、土野怪，中后期输出完全乏力。
### 防御双倍弱点
草、电双属性双倍克制，全地图随处可见对应精灵，是核心制衡短板。
### 防御抵抗：草、电，无任何属性免疫

## 五、生态与捕捉规则
1. 刷新分布：湖泊、溪流、河滩全天刷新，雨天刷新数量翻倍，野外无法直接捕捉净水神兽；
2. 抓捕道具：中级捕捉球捕获概率稳定，新手解锁水域地图即可获取；
3. 行为特征：日常沿水边慢跑，主动靠近人类跟随，遇危险只会快速逃窜，不会主动开战。

## 六、闪光异色设定
闪光水纹兽绒毛为浅青透白，体表细碎水纹微光为淡粉色，体型、种族数值无任何强化改动。

## 七、场景强度定位
1. PVE前期水域开荒过渡：T4纯进化素材杂鱼
前期小怪伤害极低时可临时上场，依靠特性小幅抵消敌方削弱debuff，核心作用仅为升到50级进化神兽；
2. PVP天梯对战：完全无上场价值
种族面板全面落后，输出、坦度、速度全部弱势，成型对战队伍不会携带。

## 八、适配队伍搭配推荐
### 最佳搭档
1. 莹花籽（草+妖精）：前期基础续航辅助，草属性抵消水系草系致命弱点，回合回复技能能耗；
2. 铁甲盔（纯土）：地面属性免疫电系伤害，遮挡水纹兽电系双倍弱点，争取输出回合；
### 天敌精灵
草系、电系任意高速输出精灵，双倍克制高额伤害可快速击倒水纹兽，直接作废特性转化收益。

## 九、整体总结
1. 完全匹配设定需求：图鉴019水纹兽，净水神兽前置形态，种族总值精准270；体型小型豹子大小，身高至人类膝盖，50级雨天净化进化净水神兽，专属特性【净羽升华】机制完全不变；温顺亲人、净化污浊的生态设定完整保留；
2. 小巧幼豹稚嫩外形，和高大鹿形猎豹流线神兽净水神兽形成鲜明体型、质感反差，进化蜕变层次感充足；
3. 同款特色反转减益特性，但极低种族数值、低速、双重属性弱点多重限制，前期强度平衡不超模；
4. 定位仅为进化素材过渡杂鱼，无竞技对战价值，唯一作用是培育解锁传说神兽净水神兽。
