# 净水神兽 完整神兽定稿（纯水独一神兽·雨天限定净化型双刀手 图鉴020）
## 一、基础设定
0. 图鉴编号：020
1. 名称：净水神兽
2. 属性：纯水系
3. 栖息规则：全大陆唯一一只传说神兽，无固定栖息点位，仅**雨天天气**全地图随机极低概率刷新，天气转晴后直接消失，错过需等待下一轮雨天
4. 进化条件：水纹兽等级50级净化进化，特殊神兽进化，无法野外直接捕捉
5. 体型尺寸：琉璃水鹿体态，身形线条像猎豹一样纤细敏捷，整体身高抵达人类脖颈位置
身高区间：1.70m ~ 1.85m，体重区间：110kg ~ 135kg
6. 性情与世界观使命：性格温和亲人，不会主动攻击人类；天生使命净化世间负面力量、污浊能量，见到被负面印记、属性削弱的精灵会主动靠近净化
7. 稀有度：传说独一神兽，全服仅存在一只，捕捉难度极高，必须使用高级专属捕捉道具
8. 对战定位：均衡型水系双刀神兽，兼具输出、反转减益的独特功能性，T0.5环境常青，有明确克制短板不无敌
9. 定型种族值（神兽标准面板）
精力125 / 物攻128 / 魔攻128 / 物防115 / 魔防115 / 速度95
种族总和：125+128+128+115+115+95 = 706
### 数值解析
1. 物攻、魔攻双128完美均衡，标准双刀输出模板，两套输出技能体系自由切换；
2. 速度95中高速梯队，多数慢速坦克精灵无法先手压制，能稳定出手触发特性反转属性减益；
3. 物防、魔防双115搭配125高额血量，耐久扎实，拥有充足站场空间持续转化负面buff；
4. 种族总值706，符合传说神兽数值标准，攻防速均衡无明显短板，同时留有属性弱点制衡强度。
### 推荐性格
天真（+速度-魔防）、急躁（+速度-物防）、均衡不加双攻减防性格
### 天赋选择
物攻、魔攻、速度、精力四项拉满极品，双防次要培养

## 二、外观设定
净水神兽本体为舒展琉璃质感水蓝色神鹿，四肢纤细修长，肌肉线条利落如猎豹，奔跑、突进动作极度敏捷；
全身皮毛是通透渐变水琉璃质感，体表流转层层流动水纹，四肢、脊背、鹿角缠绕淡蓝色水雾纹路；头顶分叉水晶鹿角，持续滴落净化清水，接触地面可冲刷泥土、驱散污浊气息；
周身常年环绕轻薄净化水雾，靠近存在负面属性削弱、印记debuff的目标时，水雾会爆发强光完成净化；
无尖锐獠牙、狰狞外形，整体气质柔和圣洁，雨天现身时周身会落下细碎无尘小雨，天晴后水雾褪去、身形逐渐消散。

进化前置区分：水纹兽体型偏小，无猎豹流线体态，鹿角短小，不具备大范围净化水雾，成长至50级雨天触发净化进化为净水神兽。

## 三、专属特性【净羽升华】
完整机制规则：
1. 转化效果：自身身上所有属性降低类减益效果，全部等额反向转化为对应属性增益
例：物攻降低30 → 物攻提升30；速度降低20 → 速度提升20；物防、魔防、魔攻减益全部同步反转加成；
2. buff留存规则：自身主动切换离场时，当前所有转化得到的等额增益完整保留；若自身被敌方击杀阵亡，全部转化增益直接清空，无法传递给下一只精灵；
3. 生效范围：仅针对自身属性增减益，无法反转敌方减益、无法清除印记类debuff，仅作用攻防速四维属性数值变化；
4. 控制状态不封锁特性：陷入睡眠、冰冻、恐惧等控制时，新获得的属性减益依旧会实时反转成增益。
### 特性平衡制衡（多重限制避免超模）
1. 仅能转化自身受到的减益，自身无主动给自己挂减益的手段，必须依靠敌方削弱才能触发增益，无对手压制则特性零收益；
2. 纯水属性自带草、电双倍弱点，草电高速输出手可先手打出高额克制伤害，即便转化少量防御加成也容易被快速压低血量；
3. 增益仅换宠保留、阵亡直接清零，无法无限叠加传承，多轮换宠体系收益存在上限；
4. 无天气增伤、能耗减免、群体辅助效果，核心机制仅单身上限反转，缺少团队辐射能力。

## 四、纯水属性攻防（沿用专属11属性克制倍率表）
### 进攻克制
水系克制火、土；抵抗草、电
可完美压制山地、火山、泥土系精灵，双倍伤害输出优势明显。
### 防御双倍弱点
草、电双属性双倍克制，全地图高频存在，是制衡神兽强度的核心短板。
### 防御抵抗：草、电，无属性免疫

## 五、生态与获取规则
1. 刷新机制：全域随机雨天限定刷新，全大陆仅此一只，捕捉成功后不再二次刷新；天晴强制消失，未对战直接离场；
2. 进化路径：普通精灵水纹兽50级，处于雨天环境下自动触发净化进化，无需额外道具；
3. 抓捕道具：仅传说专属捕捉球可稳定捕获，普通、中级捕捉球捕获概率极低；
4. 互动行为：人类主动靠近不会发起攻击，会低头释放净化水雾，清除玩家身上的负面buff；遇到被黑化、负面强化的野怪会主动上前净化。

## 六、闪光异色设定
闪光净水神兽通体淡青琉璃色，水纹光晕改为浅紫，鹿角水晶通透乳白色；体型、种族数值无改动，仅外观特效变色。

## 七、场景强度定位
1. PVE全地图开荒：T0.5顶级神兽
BOSS大量施加属性削弱debuff，净水神兽可完美反转减益化为高额攻防加成，双刀均衡输出稳定斩杀火、土系BOSS，自身高额耐久不容易暴毙；雨天环境出场自带环境契合度。
2. PVP天梯对战：T0.5梯度神兽
专门克制各类降攻、降防、减速的削弱流队伍，转化减益后攻防数值大幅暴涨；但草、电高速精灵是天然天敌，存在稳定克制手段，不会成为非ban必选无解存在。

## 八、适配队伍搭配推荐
### 最佳搭档
1. 花草土龟/枯树干（纯草）：草系联防抵消水系草属性致命弱点，轮转换宠体系保留净水神兽转化的高额增益；
2. 钢壳虫/岩颅凶狼（纯土）：地面属性免疫电系伤害，完美遮挡水系电系双倍弱点，站场承伤为净水神兽创造输出环境；
3. 宝天鹅（纯水）：清除敌方各类印记debuff，避免敌方叠加特殊印记限制净水神兽输出；
### 天敌精灵
草系、电系高速物攻/魔攻手，双倍克制高额伤害可快速击穿净水神兽基础耐久，来不及叠加转化增益就完成击杀。

## 九、整体总结
1. 完全贴合设定需求：图鉴020纯水传说神兽净水神兽，猎豹流线敏捷琉璃水蓝鹿造型，身高至人类脖颈；温和亲人、净化邪恶的世界观设定，全服唯一、雨天限定刷新；水纹兽50级净化进化，双刀定位完整保留；神兽标准706种族总值、专属特性【净羽升华】机制不变；
2. 鹿身豹形独特神兽外观，和鱼类、龟类常规水系精灵形成巨大外形区分，圣洁净化的神兽人设辨识度拉满；
3. 独有的减益反转增益机制上限很高，但绑定敌方削弱、双属性致命弱点、阵亡清空buff多重制衡，不会破坏对战环境平衡；
4. 定位顶级T0.5传说神兽，推图、天梯均有亮眼发挥，拥有明确克制天敌，做到强度高但不无敌，符合神兽设计标准。
