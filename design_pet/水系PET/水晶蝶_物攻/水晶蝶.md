# 水晶蝶 最终定稿（按你全部修改要求整合，含完整评测）
## 一、基础档案
1. 属性：纯水系
2. 栖息：新手村溪流岩壁水域，与净水鱼、熔岩鱼同区域可捕捉
3. 两段进化
    一阶：晶水珠蝶（捕捉幼体）
    二阶：水晶蝶（最终完全体，水水晶蝶立绘）
4. 定位：针对性水系物攻快攻手，不极端碾压地面体系，泛用性适中

## 二、定型种族值（严格执行修改指令）
精力120 / 物攻120 / 魔攻62 / 物防84 / 魔防86 / 速度75
种族总和：120+120+62+84+86+105 = **547**
### 面板说明
1. 基础物攻下调至120，基础速度下调至105，削弱裸装基础强度，缓解过度针对地面的问题；
2. 保留120生命小幅提升容错，双防维持84/86不变，保留脆皮制衡短板；
3. 魔攻62完全作废，纯单物攻输出，打击面仅克制火、土两类属性。
### 推荐性格
开朗（+速度-魔攻），努力分配：物攻252、速度252，剩余6精力

## 三、三段外观设定
1. 一阶·晶水珠蝶
迷你透明水晶体小虫蝶，翅膀布满淡蓝水晶纹路，常依附溪流岩石，依靠水光伪装，无攻击性。
2. 二阶·水晶蝶（完全体）
巨型半透明水晶水蝶，六片翅膀由液态净水凝结水晶构成，翅脉流淌水光，翅边垂挂细碎水珠；依靠水汽低空悬浮，**无法高空自由飞行**，匹配特性判定逻辑。

## 四、专属特性【水晶追猎】（最终版规则）
敌方精灵满足**站在地面、无法自由飞行**任意一种时：
自身固定物攻+30、速度+30；
### 硬性平衡规则（防止超模）
1. 敌方切换为**飞行属性精灵**，物攻、速度全部加成立刻清空，面板退回基础120物攻、105速度；
2. 加成仅本场战斗生效，自身换宠离场、阵亡后重新上场，需重新判定敌方属性才能触发；
3. 仅进攻、速度双数值加成，不附带减伤、回血、回能耗、免控、团队增益等额外效果；
4. 加成无多层叠加，固定仅+30物攻、+30速度，不随敌方数量提升。

### 触发后满状态面板
物攻：120+30=150，速度：105+30=135

## 七、完整平衡性评价
### 1、优化后改善的核心问题（解决“太针对地面系”）
1. 基础物攻、速度同步下调，裸身面板大幅削弱，无特性时只是中游输出，不会无差别强势；
2. 满加成物攻150属于游戏一线中等爆发，不再是天花板物攻，面对高物防肉盾不会一刀秒杀；
3. 基础速度105，不加成仅中游速度，大量高速电、草宠可稳定先手压制，不会全程超速。

### 2、优势区间
1. PVE开荒（森林、山地、雪山）：T1中游优质输出
野外绝大多数野怪为地面/无法飞行单位，稳定135高速先手、150物攻，水系克制火土，清理小怪流畅，120血量提升基础容错。
2. PVP对阵地面、虫、斗、草无飞行阵容：T2偏上针对性挂件
稳定先手压制低速前排花草土龟、壤孢巨蕈，有稳定输出优势，但无法做到单方面碾压。

### 3、多重制衡短板（锁死强度，绝不超模）
1. 飞行系完全克制：遇飞行宠直接白板，输出、速度全部归零，六翼火蝶可完美反制；
2. 脆皮生存短板不变：物防84、魔防86，吃到草、电双倍克制伤害两回合极易阵亡，高额输出缺少站场续航；
3. 打击面单一：龙、灵、金属性全部抵抗水系，满加成打这类精灵依旧刮痧；
4. 无任何团队辅助、续航、保命机制，仅单点输出挂件，无法支撑整套体系。

### 4、综合结论
本次修改完美解决“过度针对地面系”的问题：裸身面板偏弱，仅对阵地面/无飞行目标才有明显提升，面对飞行、电草天敌直接疲软；
加成数值适中、存在清晰克制链压制，PVE手感舒适，PVP泛用性有限，整体强度均衡可控，不存在超模风险，可直接定稿使用。
