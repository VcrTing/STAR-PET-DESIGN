# 宝天鹅 完整定稿（种族小幅加强+特性修正：清空一整类全部印记）
## 一、基础档案
名称：宝天鹅
属性：纯水系
生态：通体雪白羽翼柔顺优雅，胸口镶嵌通透水属性宝珠，常年安静栖息湖泊、浅滩水岸；战时催动宝珠净化敌方力量，转化为自身水系攻势
进化链：雏水鹅 → 宝天鹅（最终形态）
定位：T1耐久干扰特化魔攻手，上限提升但存在多重硬性制衡，无法达到T0超模梯队
固定数值调整：精力120，物攻95，魔攻100，物防120，魔防140，速度100

## 二、定型种族值
精力120 / 物攻95 / 魔攻100 / 物防120 / 魔防140 / 速度80
种族总和：120+95+100+120+140+100 = 655
### 面板解析
1. 物攻上调95、魔攻上调100，输出底子小幅补强，对比原版刮痧输出有所缓解，但无招式威力加成，基础伤害依旧中等偏下；
2. 物防120、魔防140顶尖耐久，血量120中等容错，专门抗压火、土系常规输出；
3. 速度100中速梯队，藤蔓蛇（110）、高速电/草精灵稳定先手，容易被克制双倍伤害压制；
4. 纯水系双重致命弱点：草、电，双倍伤害会大幅抵消高额双防优势，无法无限站场。
推荐性格：狂妄（+魔防-物攻）
努力分配：252精力、252魔防、6速度

## 三、两段外观
1. 一阶·雏水鹅：浅白色幼鹅，胸口仅有细小淡蓝水珠结晶，常在浅滩玩水，无战斗能力。
2. 二阶·宝天鹅：修长优雅白鹅，羽翼泛水光；胸口嵌一颗圆润蓝色宝珠，战斗时宝珠发光净化敌方印记，同步汇聚水流释放法术，平时安静浮在水面伪装普通水鸟。

## 四、专属特性【凝珠涤印】完整规则（按你的要求：清除一整类印记，不分层数）
回合结束阶段，若自身本回合存活未阵亡：
1. 随机清除敌方**一整类能力强化印记**，该类别下无论堆叠1层还是99层，全部一次性清空；
2. 每成功清空完整一类印记，自身永久物攻+20、魔攻+20；
3. 自身切换离场、阵亡时，清空所有叠加获得的双攻加成；
4. 仅可清除物攻、魔攻、物防、魔防、速度五类属性强化印记；无法清除异常状态、护盾、场地、天气、持续回合伤害类效果。
### 平衡制衡枷锁（锁死T1强度，杜绝超模）
1. 启动门槛苛刻：必须完整扛完敌方一回合全部输出活到结算，高速草/电克制宠先手双倍爆发可直接击杀，特性完全无法触发；
2. 单次仅随机清除一类印记，对手同时堆叠多种强化时无法一次性全部瓦解，压制存在明显短板；
3. 叠加双攻切换即清零，不能提前攒满攻击切上场收割，长线运营能力受限；
4. 无任何自保、免控、续航、减伤附加效果，生存完全依赖裸面板，被控后极易断输出节奏；
5. 水系打击面狭窄，仅克制火、土，草、电、龙、妖精全部抵抗水系招式，叠满双攻也很难快速斩杀克制自身的精灵。

## 七、全方位强度评价
### 一、本次种族加强带来的提升
1. 物攻95、魔攻100基础输出提高，配合特性清空印记叠加双攻后，伤害成型速度更快，不再全程极度刮痧；
2. 对抗花草土龟、藤蔓蛇、枯树干、三地鼠这类依赖堆叠强化的精灵压制力显著提升，一回合清空满层印记同时白嫖高额双攻，残局收割能力上涨。

### 二、多重硬性短板牢牢锁定T1，不会晋升T0
1. 成型依赖持续站场，天敌遍地
速度100低于主流高速草、电打手，对手先手双倍伤害持续压低血量，很难连续多回合存活叠加多层双攻；
2. 面对无强化快攻体系特性完全白板
大量高速输出精灵不靠等级强化打伤害，此时无印记可清除，无法获得双攻加成，只是一个高防低伤普通肉盾；
3. 战术灵活性极差，无法换场运营
叠加的双攻一旦下场全部清零，只能全程硬扛伤害站场，容错远低于水圣兽、白洁天鹅等水系核心；
4. 缺少斩杀手段，泛用性偏低
水系克制面单一，遇到抵抗水系的精灵，即便叠高双攻输出依旧乏力，必须搭配其他多属性输出精灵组队，无法单人通关地图、单人天梯上分。

### 三、分场景定位
1. PVE开荒：T1特化耐久干扰挂件
长期堆叠强化的火、土BOSS战发挥亮眼；遭遇森林草系、雷电系精英极易暴毙，自身输出不足以单刷，必须搭配输出队友。
2. PVP天梯对战：T1慢速消耗对策卡
专门克制单属性叠层体系；天梯主流草、电高速快攻体系完美克制，很难稳定触发特性，不适合作为通用上分核心。

## 八、综合总结
1. 完全遵循修改需求：魔攻上调100、物攻上调95，特性效果为存活到回合结束清除敌方一整类全部印记，每清一类自身双攻+20；
2. 小幅加强基础输出提升了对局上限，但启动条件、随机清印机制、离场清空加成、双重属性弱点等核心制衡全部保留，整体稳定卡在T1梯队，无T0无解超模风险；
3. 机制与胸口宝珠净化力量转化攻击的人设高度契合，设计逻辑闭环，水系内部精灵分层清晰，不会挤压水圣兽、白洁天鹅的出场价值，可直接定稿使用。
