# 无限鲤 完整完善定稿（纯水｜鱼龙王二阶前置精灵，图鉴009）
## 一、基础设定
0. 图鉴编号：009
1. 属性：纯水
2. 栖息点位：终湖中层水域、大型内陆湖泊深水区，宝贝鲤进化后栖息区域，临近鱼龙王沉睡的深海王殿外围
3. 整体定位：中高速过渡期均衡物攻主力，强度中等不强不弱，鱼龙王完整弱化版本，共享专属特性瀚海聚能，40级由宝贝鲤进化而来；持有道具「深海王印」可继续进化为图鉴010鱼龙王（精灵王）
4. 体型尺寸：体型壮硕巨型锦鲤，身高略高于普通成年人，整体体态宽厚饱满，比一阶宝贝鲤大上数倍
5. 身高区间：0.70m ~ 1.00m，体重区间：30kg ~ 45kg
6. 性情设定：温和群居型水域精灵，族群共同巡游湖泊中层，不会主动攻击路人；若水域遭受草、电精灵入侵，会集体释放水系力量自卫，拥有水系族群护域本能
7. 稀有度：中后期常规高阶水系精灵，非传说、非BOSS，野外无法直接捕捉，仅能通过宝贝鲤进化获取
8. 进化规则：一阶宝贝鲤等级40级进化为无限鲤；携带专属进化道具「深海王印」可进阶进化为三阶精灵王鱼龙王（道具前中期无法获取）
9. 战斗行为：依托宽阔鱼尾踏水作战，前鳍硬化形成水刃作为物攻核心输出；搭配队伍水系技能持续叠加能耗减免，依靠高频水系招式持续消耗敌人，耐久中等无法长期单宠站场

## 二、外观
二阶形态：无限鲤
巨型锦鲤体态，通体铺满渐变深海蓝鱼鳞，鳞片边缘泛细碎银白海浪微光；头部生长一对短小圆润的水纹软冠，无鱼龙王巨型王者头冠，下颚短龙须仅两根。
躯干宽厚饱满，背鳍、尾鳍宽大舒展，游动时周身环绕一层稀薄水雾，无海潮领域屏障；整体气场柔和，缺少鱼龙王的王者威压，是平民高阶水系精灵形象。
周身水雾光效随瀚海聚能叠加层数变亮，层数越高水雾范围越大。

## 三、定型种族值（鱼龙王全面弱化模板）
精力105 / 物攻120 / 魔攻50 / 物防85 / 魔防80 / 速度90
种族总和：530
### 数值说明
1. 物攻120为核心输出，相比鱼龙王140大幅下调，魔攻压缩至50完全放弃法术输出，纯物攻定位不变；
2. 速度90中高速，低于鱼龙王100，先手稳定性不足，很难稳定抢先叠加能耗减免；
3. 物防85、魔防80双耐久大幅削弱，血量仅有105，承伤容错远低于精灵王，无法扛住多轮克制伤害；
4. 整体种族总和530，数值均匀削减，完美对应过渡期中等强度，不强不弱，不会碾压同期其他精灵。
### 性格推荐
固执（+物攻-魔攻）、开朗（+速度-魔防）
### 天赋推荐
物攻、速度、精力三项核心天赋拉满极品，双防天赋随缘培养，魔攻无需投入资源

## 四、专属特性：瀚海聚能（与鱼龙王机制完全一致）
完整效果：
1. 己方场上任意精灵每释放一次水系招式，无限鲤自身所有技能PP能耗-1；该减免效果可无限叠加，精灵切换下场后已叠加的减免层数完整保留；
2. 自身所有技能能耗最低锁定为0，达到0能耗后可无消耗反复释放高威力水系大招，无释放次数限制；
3. 常驻被动：自身全部水系招式伤害永久提升15%。

### 特性平衡约束（全面下调面板限制上限，平衡过渡期强度）
虽然拥有和精灵王完全相同的特性机制，但全方位缩水的面板牢牢锁住强度，不会破坏中期数值平衡：
1. 血量、双防偏低，草、电双倍克制精灵先手爆发很容易残血，难以持续站场叠加能耗减免；
2. 速度90存在大量同期高速精灵可抢先压制，打断自身水系输出循环；
3. 物攻面板相比鱼龙王降低20点，即便叠满0能耗大招，单次爆发伤害也远不及精灵王，缺少斩杀能力；
4. 无王者专属海潮领域，单纯依靠输出消耗，缺少群体辅助、场地续航手段。

## 五、纯水属性攻防（严格套用专属11属性克制倍率表）
### 进攻克制叠加
水克制：火、土；水抵抗：草、电
中期火山、山地土系野怪较多，水系输出可以稳定克制清理，开荒实用性充足。
### 防御弱点（双重双倍克制，强力制衡）
水双倍弱点：草、电，两类属性中期地图高频出现，大量高速精灵针对性克制无限鲤。
### 防御抵抗&免疫
水抵抗：草、电；无属性免疫

## 六、进化与生态获取规则
1. 一阶进化途径：宝贝鲤等级提升至40级自动进化为无限鲤；
2. 高阶进化条件：无限鲤持有「深海王印」方可进化鱼龙王，该道具前中期无法获取；
3. 刷新逻辑：野外不存在野生无限鲤，仅能培育宝贝鲤进化得到；
4. 生态行为：成群在湖泊中层巡游觅食，族群联动释放水系技能，对战时会配合队友快速叠加瀚海聚能层数。

## 七、闪光异色设定
闪光无限鲤鱼鳞底色为淡青蓝色，水雾纹路浅粉，鱼鳍带有珍珠白光；
闪光个体区间微调：身高趋近区间上限1.95m，体重趋近区间下限110kg；基础物攻小幅+4，速度依旧90，不改变弱化过渡宠核心定位。

## 八、场景强度定位
1. PVE中期湖泊/火山开荒：中等T2主力精灵
中期队伍搭配水系精灵可稳定叠加能耗减免，0能耗大招持续清理火、土野怪，推图手感流畅；但耐久短板明显，面对草、电BOSS容易暴毙。
2. PVP天梯对战：娱乐过渡功能宠
机制完整但面板全面落后，伤害、速度、耐久均不及主流精灵，仅水系娱乐队伍可短期使用，成型后依旧需要进化鱼龙王提升上限。

## 九、适配队伍搭配推荐
### 最佳搭档
1. 池云鲤/流云长龙：双水系联动，快速叠加瀚海聚能能耗减免，水系输出循环成型更快；
2. 莹花籽/萤花仙（草+妖精）：全队每回合恢复技能PP，弥补高频释放大招带来的PP消耗，龙系免疫规避龙系伤害；
3. 铁甲盔/钢壳虫（纯地面）：地面免疫电系，完美遮挡无限鲤电系致命弱点，奇数回合高额双防站场，创造稳定叠层输出环境。
### 天敌精灵
草系、电系高速输出精灵，双倍克制伤害搭配无限鲤偏低血量与双防，可快速压低血量打断叠层节奏；无水系队友的队伍，无限鲤无法叠加能耗减免，大招消耗巨大，输出循环直接瘫痪。

## 十、整体总结
1. 完全匹配设定需求：图鉴009二阶过渡精灵无限鲤，40级由宝贝鲤进化，纯水属性，瀚海聚能特性和鱼龙王完全一致；全面板均匀削弱，种族总值530，强度中等不强不弱，为鱼龙王标准弱化前置形态；
2. 巨型锦鲤温和形象和三阶鱼龙王威严深海王者形成清晰层级反差，湖泊中层群居生态和深海独霸王殿的生态划分逻辑通顺；
3. 完整继承水系核心叠能耗机制，但血量、双防、物攻、速度全方位下调，双重属性弱点进一步放大，中期数值平衡可控，不会出现强度超标问题；
4. 定位中期开荒水系主力，具备完整输出循环，但上限有限，想要登顶天梯、通关终局BOSS必须进化为鱼龙王，区分开过渡宠与精灵王的强度梯度。
