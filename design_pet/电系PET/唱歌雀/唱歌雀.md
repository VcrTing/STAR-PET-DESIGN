# 鸣光雀 完整优化定稿（压低幼体强度、新叠速特性、稳定T2电系魔攻手）
## 进化链
一阶：晴光雏雀（林间群居小黄鸟，前期杂鱼，大幅削弱面板）
二阶：鸣光雀（36级进化，最终形态，纯电魔攻，速度种族95）

## 一、外观设定不变
1. **晴光雏雀**：迷你亮黄色小鸟，阳光下带淡金电流纹路，成群合唱；玩家靠近集体四散逃跑，无法触碰，只在向阳树林刷新。
2. **鸣光雀**：明黄主体，尾羽电光蓝，头顶发光羽冠；飞行伴随清脆鸣唱，依旧群居避人，体型小巧。
属性统一：纯电系
克制：水、飞行；致命四倍弱点：地面；抵抗：电、钢

## 二、全阶段种族值大幅削弱，保证前期不超标
### 晴光雏雀（彻底压成前期观光杂鱼）
精力55 / 物攻30 / 魔攻58 / 物防42 / 魔防45 / 速度70
总和：300
面板说明：全属性全面砍低，魔攻仅58，双防极低，前期随便一只野怪都能碾压，完全没有上场战力，解决你“雏雀太强”的问题。

### 鸣光雀（最终形态，严格T2模板）
精力86 / 物攻42 / 魔攻112 / 物防68 / 魔防70 / 速度95
总和：473
面板短板：
1. 魔攻112属于中游偏低输出，无爆发，打高坦精灵刮痧；
2. 血量、双防全线薄弱，地面系招式稳定一击残血；
3. 基础速度95，仅中等速度，原生抢不过主流高速宠，只能靠特性慢慢堆叠提速。

## 三、专属特性【鸣电逐风】（按你的需求设计）
效果：自身每释放一次电系攻击技能，本场永久自身速度+10点，层数无上限。
### 机制优缺点拆解，判定整体强度不超模
#### 优势
1. 长线对局持续提速，多回合后能追上高速精灵；
2. 贴合小鸟鸣叫释放雷光、越飞越快的人设；
#### 天然巨大限制（锁死T2，无法冲T1/T0）
1. **启动极慢**：基础速度95，每回合仅+10，叠到135需要4次电系输出；对战节奏快，大概率叠不满几层就被地面系秒杀，很难吃到多层提速收益。
2. **生存无兜底**：特性只加速度，不加任何伤害、防御、血量、异常抗性；纯单一增幅，没有复合收益，对比宝可梦电系避雷针/电气皮肤差距极大。
3. **属性致命短板**：四倍弱地面，环境遍地地面物攻手，哪怕叠满速度，先手放完技能下回合直接被秒，无法持续站场叠层。
4. **无自保手段**：没有回血、减伤、控场技能，只能单纯输出叠速，被压制时毫无反制空间。

## 四、标准配招（无强力强化，输出平庸）
1. 鸣雷脆音（电系特攻95，本系核心，用来叠速度）
2. 日光闪冲（电系特攻80，阳光小幅增伤）
3. 轻羽振速（变化，自身速度+1，小幅加速叠层节奏）
4. 微光护盾（变化，微量提升魔防，续航能力极差）

## 五、完整强度综合评价（稳定T2，很难上场）
### 1. 单打PVE/PVP
纯娱乐收藏宠，短板过于明显：
- 地面系天敌随处可见，出场极易被秒杀，根本没机会多次释放电系技能叠速度；
- 魔攻偏低，即便叠满速度先手，也打不动高物防/高魔防精灵，输出刮痧；
- 身板脆，多段伤害、克制属性招式扛不住第二回合。

### 2. 组队体系
完全无法成为体系核心/优质挂件：
- 成型周期太长，需要连续多回合输出叠加速度，当前环境速攻队居多，等叠成型队伍已经崩盘；
- 无团队增益，只强化自身速度，不能辅助队友，对比水母仙子、独角兽这类功能性辅助毫无价值；
- 四倍弱点极易被对手针对，对手只需要携带一只地面精灵就能全程限制它。

### 3. 长期环境定位
纯观光、收集向精灵，仅新手前期树林图清低级小怪临时用；高难副本、排位PVP几乎零出场率，完美卡在T2梯队，不存在破坏平衡的风险。

## 六、生态设定
仅白天阳光充足的阔叶林成群刷新，持续集体鸣叫；玩家靠近立刻四散飞远，无法直接捕捉，必须使用花蜜引诱道具才能开启对战。
