# 支线BOSS：岩隧三地鼠（纯地面系｜山地支线隐藏BOSS，魔攻特化改版）

## 一、世界观与地图定位
主线顺序：森林【主线BOSS岩颅凶狼（地面）】→山地主线BOSS【森林金刚（草）】
**岩隧三地鼠 = 山地隐藏支线BOSS**
背景：大量地鼠长期在地底岩层挖掘隧道，最终融合进化成巨型三地鼠，盘踞在山地地下溶洞；玩家探索山地洞窟深处才能遭遇，不属于必须通关主线，属于奖励型挑战。
和一号主线BOSS形成反差：
岩颅凶狼：地面物攻近战猛冲BOSS；
岩隧三地鼠：**地面魔攻远程法系BOSS**，地下穿梭、操控岩土能量发动法术攻击，给玩家全新对战体验。

外形改版（适配BOSS体型）
三个粗壮鼹鼠头部从岩堆钻出，体型远大于普通三地鼠；岩土外壳布满碎石，口鼻持续喷吐浑浊土黄色能量气流；三个脑袋交替转动，从地底不断切换位置偷袭；战斗时会频繁钻入地下消失，横版场景左右随机钻出释放岩土法术。
属性：纯地面系
进攻克制：火、电、岩石、毒、钢
双倍弱点：草、水、冰（沿用地面系标准弱点，玩家前期培育的草/水系依旧有效）

## 二、种族值（彻底重构，转为魔攻特化，BOSS面板适配中期支线）
精力96 / 物攻45 / **魔攻130** / 物防72 / 魔防80 / 速度90
总和：513
面板解析
1. 物攻压低至45，彻底放弃物理输出，纯正地面法术输出；
2. 魔攻122作为核心输出，依靠远程岩土法术持续消耗；
3. 速度98偏高速，可以频繁钻地换位，机动性强；
4. 血量中等，物防偏低，草系物理招式能有效压制；魔防尚可，不被法术一招秒杀。

## 三、专属特性【隧地共振】（改编自三地鼠经典沙穴/沙之力，贴合法系定位）
所有原始威力**小于70**的攻击招式，结算最终威力×1.4；

## 四、BOSS专属配招（全部为特攻法术，契合魔攻定位）
1. 浊岩奔流（地面魔攻115，核心输出，喷涌泥浆碎石远程攻击）
2. 地脉震荡（地面魔攻90，场地震动，小幅降低敌方全体速度）
3. 岩层隐匿（变化，钻入地下，本回合无敌，下回合登场触发特性增伤）
4. 沙砾屏障（变化，自身魔防+1，提升法术耐久）

## 五、支线对战设计（横版游戏适配）
1. 触发方式：山地洞窟收集三块岩石碎片，打通地下隧道，遭遇隐藏BOSS；
2. 横版机制：BOSS频繁消失在地底，随机在屏幕左侧/右侧钻出释放技能；
3. 对战教学延伸：玩家已经学会「草、水克制地面」，此战考验**预判与精灵轮换操作**，不灌输新属性，侧重操作训练；
4. 通关奖励：稀有地面系技能光盘、高级捕捉球，属于额外福利。
