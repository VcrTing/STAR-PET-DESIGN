# 钢牙鲨 完整完善定稿（纯水｜深潭入口守门BOSS，图鉴012）
## 一、基础设定
0. 图鉴编号：012
1. 属性：纯水
2. 栖息点位：新手森林深水潭唯一入口通道，水下迷宫前置守门点，主线推进强制触发对战
3. 整体定位：高速物攻速攻型守门BOSS，标准T1强度，不存在全局无解压制能力；击败后永久解锁水下迷宫全部水域区域，仅负责镇守通道，并非终湖底层终极BOSS
4. 体型尺寸：躯体修长鲨鱼形态，站立高度和成年人类持平，整体身长数米，冲击力极强
5. 身高区间：1.70m ~ 1.80m，体长区间：5.20m ~ 6.00m，体重区间：210kg ~ 250kg
6. 性情设定：领地执念极强，只死守深水潭进出通道，任何试图进入水下迷宫的闯入者都会被高速冲撞撕咬；无主动远距离追击行为，仅在通道范围内发动进攻
7. 稀有度：剧情一次性BOSS，野外无法捕捉，仅主线流程强制对战，无进化链，独立单体BOSS
8. 进化规则：无任何前置、后置进化形态，独立单体精灵
9. 战斗行为：水中高速回旋游动，依靠修长躯体高速冲撞，核心输出为钢牙撕咬物攻招式；血量高于50%攻势凶狠狂暴，半血后失去攻击加成，输出大幅疲软

## 二、外观
巨型深水鲨鱼形态，修长流线型青蓝色光滑鱼身，表皮带有流水反光纹路；上下颌布满两排粗壮钙化钢质尖牙，牙齿坚硬如合金钢铁，咬合时会撕裂周遭水流形成白色水浪。
常态在深水通道内缓慢巡游警戒，开战之后持续高速回旋冲撞对手；血量高于50%周身环绕深蓝激流，气势凶悍；血量跌破50%进入躁动状态，游动杂乱无序，但躯体外形不会发生任何形态改变。

## 三、定型种族值（修正计算错误）
精力122 / 物攻150 / 魔攻62 / 物防90 / 魔防88 / 速度88
种族总和：600
### 数值说明
1. 物攻裸面板150，血量高于50%触发特性额外+50物攻，等效200高额物攻，单回合爆发能力优秀；魔攻仅62，即便吃到特性加成也无实战输出价值，纯粹纯物攻单输出路线。
2. 速度110属于高速梯队，游戏前期绝大多数野外、主线精灵速度低于该数值，容易被钢牙鲨持续先手压制，逼迫玩家提前准备克制精灵联防。
3. 精力132血量容错中等，物防90、魔防88双耐久普通水平，无任何防御类增益机制；血量跌破50%直接丢失全部攻击加成，输出能力大幅腰斩，给到玩家反打窗口。
4. 纯水属性固定双重双倍弱点草、电，全流程地图高频产出草、电系精灵，是限制其强度的核心平衡枷锁。
### BOSS固定性格
急躁（+速度-物防）
### 天赋说明
剧情BOSS无捕捉、培育渠道，天赋为系统固定标准值，无极品养成相关设定

## 四、专属特性：饱食锐齿
完整效果：
1. 自身当前血量＞50%阶段，自身物攻、魔攻基础数值永久+50点；
2. 血量降低至50%及以下时，立刻清空全部双攻加成，面板回归裸属性基础数值；
3. 特性仅增幅基础物攻、魔攻面板，不会提升速度、双防、血量、招式伤害倍率、续航能力；
4. 精灵切换下场、阵亡后血量判定重置，再次登场时重新根据当前剩余血量计算攻击加成。

### 特性平衡约束（半血断输出+双重属性弱点双重制衡）
1. 高额物攻加成存在硬性血量门槛，玩家只要压低血量至半血以下，就能直接废掉BOSS核心爆发，拥有稳定反打机制；
2. 自身无任何自保、续航、回血手段，半血后输出大幅下滑，无法依靠爆发快速压低敌方血线翻盘；
3. 纯水草、电双倍弱点，高速草、电精灵可先手压低其血量，快速破除特性高额物攻加成；
4. 自身无场地、控制类招式，仅依靠单纯物理爆发，应对高物防精灵时输出会明显乏力。

## 五、纯水属性攻防（严格套用专属11属性克制倍率表）
### 进攻克制叠加
水克制：火、土；水抵抗：草、电
森林、山地火、土系野怪会被其高额物攻快速清理，但玩家草、电精灵完美克制它。
### 防御弱点（双重双倍克制，强力制衡）
水双倍弱点：草、电，游戏前期、中期随处可见对应属性精灵，专门针对克制钢牙鲨。
### 防御抵抗&免疫
水抵抗：草、电；无属性免疫

## 六、关卡生态与解锁规则
1. 对战触发：抵达森林深水潭入口通道自动强制开战，无法绕开，流程硬性交战；
2. 通关解锁奖励：成功击败钢牙鲨后，永久解锁整片水下迷宫水域，开放终湖、浅水溪流等全部水下探索点位；
3. 重复挑战：解锁水下迷宫后可返回深水潭通道重复挑战钢牙鲨，无重复道具、精灵蛋奖励，仅用于练习对战机制；
4. 伴生生态：通道内无其他野生精灵，整片深水通道为钢牙鲨独占领地，也是守护宝贝鲤彩蛋精灵蛋的第一道防线。

## 七、闪光异色设定（仅重复挑战概率刷新，无法捕捉）
闪光钢牙鲨鱼身底色转为冰湖淡青色，钢牙泛银白色金属光泽，周身激流光晕替换为浅蓝白色；
闪光个体全部种族数值无改动，速度依旧110，不改变高速速攻、半血断输出核心机制。

## 八、场景强度定位
标准T1流程守门BOSS，半血前后输出差距极大，前期高速先手有极强压制力，但存在清晰稳定破解思路；只需要携带草、电系克制精灵快速压低血量，就能废掉高额物攻加成，不存在无解对局，强度可控不超模。

## 九、适配对战推荐精灵
### 最佳克制出战精灵
1. 莹花籽（草+妖精）：草属性双倍克制水系，前期森林轻松捕捉，稳定压低钢牙鲨血量快速破除特性，附带全队回合回PP续航；
2. 铁甲盔/韧甲虫（纯地面）：地面免疫电系伤害，可联防规避敌方电系精灵，同时稳定承伤等待克制精灵出场；
### 不推荐首发精灵
火系、土系精灵，会被水系招式双倍克制，极易在BOSS满血高额物攻阶段被先手重创。
