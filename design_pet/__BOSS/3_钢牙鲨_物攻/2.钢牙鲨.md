# 钢牙鲨 终稿设定（纯水系水下守门BOSS）
## 一、基础档案
名称：钢牙鲨
属性：纯水
定位：深潭入口守门BOSS，击败后解锁水下迷宫，流程强制交战，标准T1强度，无全局无解能力
生态：栖息森林深水潭入口的巨型鲨鱼，牙齿钙化坚硬如钢铁，依靠高速冲撞撕咬入侵者；只守通道，并非最终水底BOSS。
类型：物攻手
硬性数值：速度100，物攻150；特性：血量＞50%时自身双攻+50点

## 二、完整种族值
精力132 / 物攻150 / 魔攻62 / 物防90 / 魔防88 / 速度100
种族总和：132+150+62+90+88+110 = 622
### 面板解析
1. 物攻裸面板150，满血触发特性后物攻等效200，爆发能力优秀；魔攻仅62，即便加成后也无输出价值，纯物攻单路线。
2. 速度110高速梯队，新手前期精灵大多低于该速度，容易被持续先手压制。
3. 血量132中等容错，双防90/88普通耐久，无额外防御buff，血量跌破50%后输出直接腰斩。
4. 纯水属性固定双倍弱点：草、电，前期、全流程高频克制精灵，核心平衡枷锁。

## 三、外观
数米长巨型深水鲨鱼，通体青蓝光滑鱼身，上下两排粗大钙化钢质尖牙；在潭水内高速回旋冲撞，咬击会撕裂水流，半血后躁动狂暴，但不会产生形态质变。

## 四、特性【饱食锐齿】完整规则
1. 自身当前血量＞50%时，物攻、魔攻永久+50点；
2. 血量≤50%，立刻清空全部双攻加成，面板回归裸属性；
3. 仅提升基础双攻数值，不增加速度、双防、续航、招式威力倍率；
4. 离场、阵亡重置血量判定，再次上场重新按当前血量计算加成。

## 五、纯水属性攻防
进攻双倍克制：火、岩、地
防御双倍致命弱点：草、电
属性抵抗：冰、毒

## 六、配套BOSS配招
1. 钢齿猛冲（水系物攻130，核心输出，满血阶段伤害极高）
2. 涡流冲撞（水系物攻120，补伤多段输出）
3. 深水暗流（干扰，降低敌方1级速度，拉开先手差距）
4. 水膜缓冲（变化，单回合物防+8，小幅苟活维持满血状态）

# 强度完整评价
## 核心结论：稳定标准T1守门BOSS，满血压制力强，但破绽极其明显，不存在超模、无解风险
## 一、优势（血量50%以上强势阶段）
1. 高额物攻加成爆发恐怖
裸物攻150+50加成=200物攻，搭配130威力水系本招，无物防强化的精灵极易被一招打残，高速先手持续压低玩家血量，守门压迫感充足。
2. 110高速打底，前期很难被玩家精灵超速，容易全程掌握输出节奏。
3. 贴合设定：血量充足、体力饱满时尖牙破坏力拉满；受伤失血后体力下滑，攻击力度大幅下降，机制逻辑自洽。

## 二、不可弥补的多重短板，死死锁死T1梯队
### 1. 血量低于50%直接废掉核心特性，输出大幅腰斩
一旦玩家稳定压低其血量过半，加成完全消失，物攻退回150，输出直接下降一个档次，威胁大幅降低，玩家拥有清晰反制窗口。
### 2. 草、电两大双倍弱点随处可见，可快速压血破特性
水系被草、电2倍克制，玩家携带任意电系/草系精灵，双倍伤害能快速将其血量压至50%以下，直接废掉高额双攻加成，完美克制满血强势阶段。
### 3. 特性只加攻击，无任何耐久、续航增益
双防、血量无任何提升，满血阶段也扛不住多段克制爆发，很容易被集火快速打出血线缺口；没有回合回血、护盾类自保手段，无法永续维持满血强势状态。
### 4. 无残局翻盘能力，半血后全程弱势
一旦血量跌破阈值，全程无高额输出，面对肉盾精灵持续刮痧，不存在逆风一穿多的能力，和迷宫深处准T0终极BOSS拉开巨大强度差距。
### 5. 打击面单一，仅克制火/岩/地
遇上草、电、龙等抵抗/克制水系的目标，哪怕满血高额物攻，输出收益也会大幅缩水。

## 三、场景定位
1. PVE水底入口：T1门槛BOSS
前期玩家缺少草、电精灵时会被满血高伤压制；只要培养电/草系精灵，轻松压血废掉特性，通关难度平滑，不会严重卡关。
2. 无培养价值（仅BOSS，不可捕捉）
单纯流程守门怪，打完解锁迷宫，无法收入队伍，不会干扰对战环境平衡。

# 综合总结
1. 需求全部落地：纯水属性、物攻150、速度110，血量高于50%双攻+50点，水下守门鲨鱼BOSS；
2. 满血阶段爆发压迫感充足，完美起到守门检验队伍的作用，但存在**半血直接失buff、草电双倍弱点、无耐久续航**多层硬性制衡，稳定卡在T1，达不到T0强度；
3. 机制简单易懂、克制关系清晰，适合作为迷宫前置过渡BOSS，设计合格可直接定稿。
