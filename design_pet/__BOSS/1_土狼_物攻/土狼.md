# 森林首关BOSS：岩颅凶狼（纯地面系，适配新手10级精灵对战，种族全部压低缩水）
## 一、外形设定
直立双足行走巨型土狼，人型站姿，上半身肌肉壮硕厚实，肩背覆盖硬化岩土硬毛，胸口凸起岩石甲片；面部凶狠狰狞，锋利獠牙外露，赤红竖瞳，持续低沉嘶吼威慑闯入者；四肢粗壮裹满碎石泥皮，甩动泥岩长尾，走动踏地扬起尘土。
盘踞森林深处碎石洼地，主线推进强制触发对战，是玩家遭遇的第一只BOSS，领地意识极强，主动进攻主角。

## 二、属性：纯地面系
进攻克制：火、电、岩石、毒、钢
双倍弱点：草、水（核心教学点，引导新手用草/水系精灵通关）
属性抵抗：岩石、毒

## 三、最终锁定种族值（严格按你指定数值）
精力100 / 物攻100 / 魔攻10 / 物防60 / 魔防60 / 速度30
种族总和：360
面板适配新手说明：
1. 物攻100、特性开局翻倍爆发，对10级新手精灵伤害压迫感拉满，体现凶狠狂暴设定；
2. 魔攻仅10，完全放弃法术输出，只会物理攻击，简化新手对战理解成本；
3. 双防统一60，血量100，容错适中，不会被新手一招秒杀，保证教学回合充足；
4. 速度压低至30，绝大多数10级草、水系新手精灵速度更高，稳定先手打出克制双倍伤害，降低通关挫败感。

## 四、专属特性【狂躁冲袭】
效果：自身登场第一回合，物攻提升100%（翻倍）；仅首回合生效，后续回合物攻恢复基础100。
机制设计逻辑：
1. 开局高额爆发，给新手强烈压迫，直观让玩家意识到不能用被克制精灵硬扛；
2. 仅持续一回合，避免持续高额物攻直接秒杀低等级精灵，保留通关机会；
3. 逼迫玩家立刻切换草/水系克制精灵，快速学习属性克制核心规则，贴合新手教学定位。

## 五、BOSS配招（纯物理输出，适配低等级对战）
1. 碎岩猛扑（地面物攻130，核心爆发招式，配合首回合物攻翻倍伤害极高）
2. 浊泥爪击（地面物攻90，稳定补伤，无负面附加）
3. 狂怒嘶吼（变化技能，自身物攻小幅+1，持续小幅增伤施压）
4. 岩土硬皮（变化技能，自身物防+1，延长对战教学时长）

## 六、新手关卡教学逻辑
1. 战前NPC提示：林中大地猛兽畏惧草木与溪水之力；
2. 若上场火、电等被地面克制精灵，会被BOSS首回合翻倍物攻重创残血，系统弹出警告提示；
3. 切换草/水系精灵后，技能打出双倍高额红字伤害，弹出教学弹窗：地面系弱点为草、水系，使用对应精灵可轻松战胜；
4. BOSS速度仅30，新手10级草、水系基础精灵普遍速度高于30，稳定先手输出，游玩体验顺滑。

## 七、强度定位
纯新手教学BOSS，开局爆发强但短板清晰，种族整体大幅缩水适配低等级精灵；无无解机制，仅依靠草、水系初始赠送精灵即可稳定通关，完美完成属性克制入门教学。
