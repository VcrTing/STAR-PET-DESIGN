# 森林金刚 完整优化定稿（纯草系大猩猩BOSS，数值按要求调整，机制、外形全部保留）
## 一、外形设定
本体是直立巨型银背大猩猩，体型如同山岳巨人，远观极具压迫感，勾起玩家挑战欲；全身厚重深褐皮毛，肩背、双臂、头顶缠绕粗壮藤蔓与阔叶，胸口生长古树纹路；肌肉夸张壮硕，单臂可掀翻巨石，神态凶狠威严。
栖息密林最深处古树高台，远处就能看见巨大身形，靠近会发出震地咆哮，行动沉重缓慢，战斗依靠藤蔓重拳、地下树根发起进攻。
属性：纯草系
### 属性攻防
进攻克制：水、岩石、地面
双倍弱点：火、冰、飞行、虫（多重稳定克制，平衡强度）
抵抗：水、电、草、地面

## 二、调整后种族值（仅修改攻防双攻，精力、速度不变）
精力130 / 物攻119 / 魔攻109 / 物防121 / 魔防101 / 速度50
种族总和：630
面板解析
1. 物攻119＞魔攻109，偏物理双刀，重拳输出更突出，法术藤蔓作为补充伤害；
2. 物防121、魔防101，高额双耐久，站场能力极强，足够完整运转储能特性；
3. 速度固定50低速，玩家火系、飞行高速精灵稳定先手压制；
4. 血量130打底，生存能力拉满，拉长对战回合，充分展现专属能量机制。

## 三、专属特性【林源储能】（规则完全不变）
完整机制细则
1. 战斗开局自身能量固定为0；
2. 全场所有精灵（包含BOSS自身）每释放1次草系技能，能量+4点；BOSS模式下自身释放草招式同样计入积攒；
3. 能量无上限，整场战斗不会清空，仅战斗结束/自身阵亡重置；
4. 积攒足量能量可释放专属高额必杀。

博弈逻辑
1. BOSS频繁使用草系技能快速叠能量，逼迫玩家速杀；
2. 玩家携带草系精灵能快速攒大招，但草系被火、飞行克制，极易被反打；不带草系则攒能速度极慢，消耗战难度上升；
3. 形成取舍型对战策略，区别于常规无脑输出BOSS。

## 四、BOSS配招（无改动）
### 常规四招（随机循环释放，均可积攒能量）
1. 巨木重捶（草系物攻120，近身重拳物理输出）
2. 缠根风暴（草系魔攻115，树根席卷法术伤害）
3. 密林硬化（变化，自身物防+1、魔防+1，延长对局叠能量）
4. 震地怒吼（变化，敌方全体速度-1级，弥补自身低速短板）

### 能量必杀（能量≥40点解锁，单局最多释放2次）
万藤崩山（草系混合威力150，吸取30%伤害转化自身血量，释放后清空全部能量）

## 五、强度与定位评价
1. 吸引力：巨型巨人丛林霸主外观，视觉冲击力强，玩家会主动想要挑战；
2. 作战优势：高双防+高血量，站场持久，物攻数值更高，物理招式伤害突出；独特全队储能机制，对战策略丰富；
3. 天然制衡短板：速度仅50，四大双倍弱点（火/冰/飞/虫），玩家克制精灵稳定先手压低血线；高额必杀需要长时间攒能量，输出成型慢，不会出现开局碾压新手；
4. 定位：中期森林主线标志性BOSS，机制独特、强度可控，无无解碾压能力。

## 六、生态设定
独居远古密林核心古树高台，整片区域仅存在一只；所有小型精灵主动避让；平日静坐古树顶端汲取草木能量，玩家靠近直接开战，战败后返回古树休眠，不会永久消失。
