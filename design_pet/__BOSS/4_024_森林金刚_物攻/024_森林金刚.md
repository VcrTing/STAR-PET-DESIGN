# 苔花小猩→森岩巨猩王 完整设定定稿
## 二阶：森岩巨猩王
编号：024
属性：纯草系
进化路线：苔花小猩42级进化 → 森岩巨猩王（支线秘境BOSS）
身高：高出人类两个头
定位：低速肉坦物攻队核，草系慢启动叠能型BOSS
生态：秘境深处的森林霸主，平日静坐在古树根系之间，领地意识极强。身躯自带草木岩甲，不会主动走出秘境范围。不轻易发起进攻，一旦遭到挑衅便会奋力反击，是森林支线标志性镇守BOSS。

### 外观设定
巨型森林猩猩，身形敦实魁梧，双臂宽厚充满爆发力。体表皮肤呈深褐古木色泽，背部蔓延厚重苔藓，丛生小型灌木，混杂天然岩石构成硬质铠甲；面部线条硬朗威严，眼神沉静肃穆。周身萦绕淡淡的草木雾气，行动时震落枝叶碎石，自带森之王者气场。

### 种族值
精力135 / 物攻130 / 魔攻60 / 物防125 / 魔防110 / 速度40
种族总和：600

### 专属特性【森王蓄能】
初始能量=0；自身在场时，己方任意精灵每释放一次草系技能，自身能量+3。
能量梯度效果：
能量≥12：物防、魔防提升25%
能量≥24：物攻额外提升30%
能量≥36：所有草系攻击招式威力提升15%
切换离场能量清零。

## 一阶：苔花小猩
编号：023
属性：纯草系
进化条件：42级进化为森岩巨猩王
身高：到人类腰部位置
定位：野外普通野生精灵，前期草系肉坦备选，成长潜力高，成型缓慢

### 外观设定
小圆脸幼年猩猩，体态小巧圆润，性格憨厚温顺。背部覆盖一层柔软青苔，零星生长细碎白色小花，四肢短小，行动慢吞吞，受到惊扰只会蜷缩身体依靠苔藓伪装。

### 种族值
精力92 / 物攻90 / 魔攻40 / 物防82 / 魔防76 / 速度32
种族总和：412

### 专属特性【森王蓄能】
初始能量=0；自身在场时，己方任意精灵每释放一次草系技能，自身能量+3。
能量梯度效果：
能量≥12：物防、魔防提升15%
能量≥24：物攻额外提升20%
能量≥36：所有草系攻击招式威力提升10%
切换离场能量清零。

## 对战综合评价
森岩巨猩王极度依赖草系技能持续叠层，低速短板明显，开局攻防平平，属于典型慢启动精灵。高速压制、草系封锁手段可以有效限制叠能节奏，不会出现无脑压制对局；作为支线BOSS，能够引导玩家学会打断叠层持续增益的对战思路。
