# 树虱仔 优化终稿（树上小虫、T3凑数小怪，调整种族+强化特性）
## 一、基础档案
名称：树虱仔
属性：纯草系
生态：指甲盖大小嫩绿色林间小虫，成群趴在树干、叶片背面吸食树汁；不会主动进攻玩家，仅作为森林填充小怪，无培养、对战价值，固定T3梯队，无进化形态。
定位：纯场景凑数小虫，面板小幅补强但整体依旧垫底，不会威胁主流精灵平衡。

## 二、调整后种族值
精力62 / 物攻80 / 魔攻49 / 物防70 / 魔防70 / 速度40
总和：62+80+49+70+70+40 = 371
### 面板解析
1. 物攻上调至80，对比原版刮痧小幅改善，但无任何增伤特性，输出依旧乏力；魔攻完全废弃，不走法术路线。
2. 物防、魔防统一拉到70，基础耐久小幅提升，不会被小怪一击秒杀，但碰到主流克制精灵依旧扛不住两轮伤害。
3. 血量62偏低、速度40极低速，核心短板完全保留，永远后手挨打。
4. 草系经典弱点：火、飞行、毒双倍克制，环境克制单位随处可见。

## 三、外观不变
指甲盖大小分节嫩绿小虫，背带树皮纹路，六细爪紧贴树干，受惊贴紧树皮伪装斑点，成片群居。

## 四、特性【树汁拟态】新版完整规则
敌方所有招式（物理攻击、法术攻击、给自身挂异常的状态干扰技能）命中自身概率永久降低20%；
无地形限制，全地图永久生效。
### 特性限制
1. 只降低敌方命中率，**自身没有任何增伤、回血、提速、减伤加成**；
2. 必中类招式不受该效果抵消，稳定命中；
3. 仅作用于敌方瞄准自身的判定，队友不受保护。

## 五、纯草系攻防
进攻双倍克制：水、土
防御双倍致命弱点：火、飞行、毒
抵抗：电、土

## 六、配招不变
1. 汁刺啃咬（草系物攻威力38，唯一输出）
2. 贴皮缩身（变化，单回合物防+4）
3. 树汁汲取（回合末回复2%生命值，回血几乎可以忽略）

# 完整强度评价
## 核心结论：依旧牢牢锁死T3，只是小幅提升生存恶心度，完全不超模，依旧没有上场价值
## 一、本次改动带来的小幅提升
1. 物攻80+双防70，面对同等级新手杂鱼小怪有微弱对抗能力，不再一碰就碎；
2. 全局20%全体闪避（含异常技能），干扰类、多段普攻很难稳定挂上灼烧、中毒、降属性，成群出现时会轻微拖慢玩家清怪速度，贴合“烦人小虫”的林间设定；
3. 取消地形限制，脱离树林也能保持闪避效果，机制更统一。

## 二、多重硬性短板，牢牢压住强度，无法升级至T2
1. 速度40全场最低一档，永远后手挨打
即便有20%闪避，对手连续多次出手总有命中机会，持续承受伤害，容错极低。
2. 基础输出严重不足
物攻80但输出招式仅38威力，无任何伤害增幅，哪怕克制水系、土系目标也全程刮痧，没有斩杀能力，完全没法打BOSS和对战。
3. 血量仅62，耐久底子薄弱
双防70只是小幅缓冲，火、飞行、毒双倍克制伤害命中后，几乎直接残血，撑不住第二下克制攻击。
4. 存在必中招式克制，特性有明确天敌
游戏内大量主流精灵持有必中技能，直接无视20%闪避，轻松稳定击杀树虱仔，完美抵消特性优势。
5. 无进化、无成长上限，纯一次性野外小怪
不能长期培育，后期玩家精灵属性全面碾压，20%闪避、80物攻完全起不到任何作用，一碰就清。
6. 无任何团队功能性
只能自保闪避，不能给队友提供护盾、减益、提速等辅助，组队完全没有战术价值。

## 三、场景定位
1. PVE森林野外：T3填充杂鱼，成群出现会轻微浪费玩家时间，单只毫无威胁；
2. 中后期推图/PVP：完全仓管废件，不存在任何组队、上场可能性，对比T2嗜金蚊差距巨大。

## 综合总结
1. 全部修改需求落地：物攻80、物防魔防各70；特性全局降低敌方20%命中，覆盖攻击、挂异常类技能；
2. 小幅补强输出与耐久、强化闪避机制，但低速低血量、低威力招式、双倍弱点、必中克制、无进化成长等核心短板全部保留；
3. 依旧是标准T3凑数小虫，仅轻微提升野外恶心程度，不会破坏整体精灵梯度平衡，设计合格可定稿。
