# 藤蔓蛇 完整设计定稿（纯草系高速双刀手，速度叠双攻特性，完整强度评测）
## 一、基础档案
1. 名称：藤蔓蛇（最终形态）
2. 属性：纯草系
3. 生态：常年悬挂树枝，藤蔓身躯下垂伪装成藤蔓，不主动触发战斗很难分辨；高速突袭型精灵
4. 栖息：森林大树树冠、林间高地，野外普通可捕捉，无稀有限定
5. 进化链：两段进化
    一阶：细藤幼蛇（幼体，细藤蔓缠绕树枝）
    二阶：藤蔓蛇（完全体）
6. 固定硬性数值：速度110，物攻110，魔攻112

## 二、定型种族值
精力108 / 物攻110 / 魔攻112 / 物防82 / 魔防84 / 速度90
总和：108+110+112+82+84+110 = **586**
### 面板制衡拆解
1. 速度110属于上游高速梯队，开局稳定先手，但双防仅82/84、血量108，生存面板全线脆皮，吃到克制双倍伤害极易残血；
2. 物攻110、魔攻112均衡双刀，基础输出中游，无原生增伤，必须依靠特性提速叠攻才能拉高伤害；
3. 无耐久、无保命、无团队辅助面板分配，完全偏向纯速攻，牺牲全部生存换速度。
推荐性格：天真（+速度 -物防）/急躁（+速度 -魔防）；努力分配：252速度、252物攻、6魔攻

## 三、两段进化外观
1. 一阶·细藤幼蛇：通体细绿藤蔓，缠绕树枝下垂，和普通林间藤蔓完全混淆，体型小巧。
2. 二阶·藤蔓蛇：修长藤蔓躯干，枝叶遍布全身，悬挂树冠自然垂落伪装；开战舒展藤蔓高速缠绕突袭，尾部叶片可同时打出物理、特攻双伤害。

## 四、专属特性【藤影增速】完整规则
自身**当前总速度每高出基础速度10点**，永久物攻+5、魔攻+5，层数无上限；
### 关键规则&制衡枷锁（防止叠满无解）
1. 仅**自身速度属性变化**计算层数（自身提速技能、花草土龟/水晶蝶队友提速均可叠加；敌方降速不影响自身层数）；
2. 速度加成带来的双攻永久保留，切换离场不清除，仅阵亡后全部清零；
3. 纯草系五大双倍弱点：火、飞行、冰、毒、虫，高速天敌遍地，叠层过程全程承受高额克制伤害；
4. 自身双防、血量极低，无护盾、无回血，一旦被高速克制宠先手压制，来不及叠层直接暴毙；
5. 仅强化自身输出，无法给队友提速、增伤，无团队联动增益。

### 叠层数值举例
自身速度叠+30 → 物攻110+15=125、魔攻112+15=127；
叠+60速度 → 物攻140、魔攻142，达到一线输出水平，但成型需要多回合持续提速铺垫。

## 五、纯草系属性攻防（沿用你的11属性克制规则）
进攻双倍克制：水、土
防御五大2倍致命弱点（核心制衡）：火、飞行、冰、毒、虫
防御抗性：水、土、电

## 六、适配双刀配招（兼顾物攻、魔攻、提速铺垫）
1. 藤鞭撕裂（草物攻 威力130，核心物理输出）
2. 毒叶风暴（草魔攻 威力128，核心特攻输出）
3. 疾风缠藤（变化，自身速度+1级，用来快速叠特性双攻，无伤害）
4. 藤蔓束缚（干扰，降低敌方1级速度，仅控速不叠加自身层数）

## 七、全方位强度完整评价
### 一、机制优势与设计亮点
1. 人设高度契合：藤蔓蛇依靠高速藤蔓舒展提速，速度越快藤蔓力量越强，同步提升物攻魔攻，双刀机制贴合生态；
2. 110基础高速开局稳定先手，配合「疾风缠藤」可快速叠速度，短回合内拉高双攻，成型后斩杀能力可观；
3. 纯草系双刀补盲，物攻、魔攻双线输出，不用纠结单路线培养，开荒水系、土系小怪清图流畅；
4. 可搭配水晶蝶、枯树干、仿石蘑菇草系联防队，队友提速buff能同步放大自身特性收益，草系娱乐队核心输出。

### 二、多重硬性短板牢牢锁死强度，**不会超模、不会挤压其他精灵**
#### 1、生存面板底层致命缺陷，容错极低
血量108、双防80出头，纯草系五大主流双倍弱点，火、飞行、冰全是环境高频高速宠；哪怕开局先手，一旦对方携带克制技能，两回合直接残血，很难撑到多层速度叠满。

#### 2、成型存在回合门槛，前两回合输出刮痧
基础双攻仅110/112，不叠速度时伤害中游偏下；必须使用提速技能铺垫2~3回合才能打出高额输出，对战快攻体系会被直接压制，没有成型窗口。

#### 3、泛用性受限，脱离提速体系强度暴跌
队伍无提速辅助、不带自身疾风缠藤时，特性仅基础速度110，只能每层+0双攻，就是普通高速双刀，对比水晶蝶、极冰雪熊无任何优势。

#### 4、无任何自保、续航、团队增益功能
不像枯树干长线叠防御、花草土龟退场全队双抗、萤花仙全队回PP，藤蔓蛇只能单打独斗输出，队伍功能性几乎为0，仅负责打伤害。

#### 5、打击面狭窄，大量属性刮痧
草系输出对火、飞、虫、毒、龙、金属性全部抵抗，即便叠满双攻，面对高耐久肉盾（花草土龟、极冰雪熊）持续刮痧，必须搭配多属性队友补盲。

### 三、分场景精准定位
1. PVE开荒：T2偏上高速输出
无火、飞行、冰怪的水系、土系场景发挥优秀；遇到火系、飞行精英/BOSS极易暴毙，无法单人通推全图，替代不了极冰雪熊开荒战神地位。
2. PVP天梯对战：T2特化草系快攻挂件
纯草消耗队专属输出，依靠高速叠双攻完成收割；天梯主流火系、飞行快攻体系完美克制，上场容易被先手秒杀，完全不具备通用上分能力。

## 八、综合总结
1. 完全满足你的全部需求：纯草藤蔓蛇、悬挂树枝伪装藤蔓、速度110、物攻110、魔攻112，特性自身速度每高出基础10点双攻+5；
2. 机制理论上限可观，但**脆皮五弱点、成型需要铺垫、泛用性低、无自保能力**四层强力制衡，整体强度可控，不存在前期无脑碾压其他精灵的问题；
3. 定位草系专属高速双刀输出，特色鲜明但天敌清晰、使用门槛高，和枯树干、仿石蘑菇、花草土龟形成稳定强度分层，各精灵拥有不可替代功能，环境平衡无风险，可直接定稿使用。
