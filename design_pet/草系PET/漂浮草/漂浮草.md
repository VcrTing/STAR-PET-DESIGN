# 完整优化定稿：丸叶团子 → 天翊四叶（水+草 T2弱势精灵）
## 进化链
一阶：丸叶团子（初始形态）
二阶：天翊四叶（42级进化，最终形态，可飞天、仅能降落水域）

## 一、一阶 丸叶团子
### 外形
圆滚滚开心水草丸子娃娃，粉腮红，常年大笑；头顶一片超大圆形浮水阔叶，依靠叶片漂浮河面池塘，无法离地，只会在水面缓慢滚动。
属性：水+草
种族值（过渡杂鱼）
精力72 / 物攻63 / 魔攻70 / 物防68 / 魔防65 / 速度55
总和：393
特性：浮叶缓行
自身在水面速度+10，离开水面速度减半，无输出增益。

## 二、二阶 天翊四叶（优化后全部数值+新特性）
### 外形
本体软嫩青草丸子，保留笑脸；头顶进化成四片轻薄水汽四叶草，风大即可升空飞行；可自主飘飞，但降落强制选择河流、湖泊水域，落在无水地形会僵直；飞行飘散青草水珠，无任何攻击性。
属性：水+草
### 最终调整种族值（严格按你的要求）
精力98 / 物攻**20** / 魔攻**100** / 物防78 / 魔防76 / 速度**50**
总和：501
面板短板拆解
1. 物攻压至20：彻底废掉物理输出，完全只能靠魔攻打伤害；
2. 魔攻刚好100：中等偏低特攻，即便有特性增伤也打不出高额爆发；
3. 速度砍至50：全场低速梯队，绝大多数精灵稳定先手压制，根本没机会叠特性buff；
4. 精力98、双防78/76：身板极脆，任意克制属性招式基本一击残血；
5. 种族总和偏低，和主流T1/T0精灵差距巨大。

### 专属特性【润叶增翠】
效果：自身每释放一次水系技能，本场战斗草系招式伤害永久+20，可多层叠加，无上限。
#### 机制短板（保证T2不会变强）
1. 叠伤需要连续释放水系技能铺垫，低速50很难多次出手叠加层数；
2. 水+草属性四倍弱毒，虫、飞、火、冰双重弱点，没叠几层就容易被直接秒杀；
3. 仅增草系伤害，水系技能本身无任何加成，两套输出分开，成型慢；
4. 无保命、提速、续航配套效果，纯单向增伤，生存完全没有兜底。

### 属性攻防（天生弱势，极易被乱杀）
四倍弱点：毒
双倍弱点：虫、飞行
常规弱点：火、冰
抗性极少，进攻打击面盲点多，属性天然吃亏。

### 适配配招（贴合特性，无强力战术）
1. 青岚草浪（草系特攻90，核心输出，靠特性叠伤害）
2. 溪流轻拍（水系特攻70，用来叠加特性增伤层数）
3. 光合薄愈（草系变化，每回合仅回6%最大血量，回复微薄）
4. 飘风跃迁（变化，飞天，下一回合强制落水，无水地形掉血僵直一回合）

## 三、强度综合评测（稳定T2，上场容易被乱杀）
1. 速度50致命缺陷：出手权极低，经常来不及放水系叠增伤就被对手击杀，特性很难发挥价值；
2. 输出上限有限：魔攻仅100，哪怕叠两三层增伤，也秒不掉常规坦系精灵；物攻20彻底报废物理手段；
3. 生存拉胯：血量、双防全部偏低，四倍弱毒是环境高频属性，毒系精灵出场直接碾压；虫、飞、火、冰随处可见，全是克制它的对手；
4. 场地机制束缚：飞行落地只能选水域，无水场地落地扣血+僵直，大幅限制出场地图；
5. 定位：纯观赏收藏精灵，休闲玩水图可以娱乐，PVP、高难副本完全无法使用，属于标准T2弱势精灵。

## 生态设定
栖息湿地、溪流、浅池塘；丸叶团子成群浮在水面；天翊四叶随风集体升空漫游，风势减弱就寻找水域降落，性格温顺只会逃跑，不会主动发起战斗。
