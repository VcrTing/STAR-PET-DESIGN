# 辣椒炮手 终稿（最终优化版）
## 一、基础档案
名称：辣椒炮手
属性：草+火
生态：拟人辣椒主干身躯，左手拎红辣椒串、右手拎黄辣椒串，以投掷爆裂辣椒炸弹作为法术攻击；平时扎根农田、火山坡，静止时和普通辣椒丛难以区分。
进化链：小椒苗 → 辣椒炮手（最终形态）
定位：慢速蓄力特化魔攻炮台，前期稳定T2弱势，长时间叠满印记后输出上限极高；高速飞行/岩石/毒系快攻为天然天敌，整体不超模。

## 二、定型种族值（本次优化调整：魔攻138→130，魔防88→100，其余不变）
精力112 / 物攻70 / 魔攻130 / 物防85 / 魔防100 / 速度72
种族总和：112+70+130+85+100+72 = 569
### 面板说明
1. 魔攻下调至130，基础输出小幅降低，进一步压低前期无印记刮痧阶段的强度，稳固T2定位；
2. 魔防提升至100，法系承伤小幅改善，更容易苟回合堆叠爆辣印记；物防、血量依旧偏低，物理克制单位依旧能快速压血；
3. 速度72低速梯队，绝大多数精灵稳定先手；物攻完全废弃，纯魔攻体系；
4. 进攻克制水、岩石、地面、冰、虫；防御三重双倍弱点：飞行、毒、岩石。
推荐性格：保守（+魔攻-物攻）
努力分配：252魔攻、252精力、6魔防

## 三、两段外观
1. 一阶·小椒苗：纤细辣椒幼苗，仅挂两颗小型辣椒，仅能释放微弱火苗，无轰炸能力。
2. 二阶·辣椒炮手：粗壮拟人辣椒主干，叶片化作简易披风；左右手各悬挂红黄辣椒串，投掷时辣椒炸裂，火焰缠绕藤蔓形成混合法术爆炸。

## 四、专属特性【爆辣蓄印】终版规则
1. 本回合全程未使用任何攻击招式（仅释放防御、干扰、回血类变化技能），回合结束获得1层爆辣印记；本回合打出攻击则无法获取印记。
2. 每层爆辣印记常驻效果：
   ① 自身所有火系技能威力+30，无层数上限；
   ② 每释放一次草系技能，立刻回复2点能量，保障技能循环。
3. 切换离场、精灵阵亡时清空全部爆辣印记，重新上场需牺牲输出回合重新堆叠。
4. 仅攻击型招式、变化技能区分判定；护盾、扎根、降速、回血均属于可叠印记的安全招式。

## 七、完整强度评判（是否超模）
### 核心结论：不超模，完美达成「前期T2、长线成型后高上限」的设计目标
### 一、本次优化改动带来的变化
1. 魔攻下调10点，无印记阶段输出更低，前期对抗任何精灵都很难打出有效斩杀，牢牢锁死T2梯队；
2. 魔防提升12点，面对水系、地面法系精灵生存容错提高，更容易撑过多回合堆叠印记；
3. 单层印记火系加成上调至30，多层堆叠后的爆发上限显著提高，成型后收割能力更强。

### 二、多重硬性制衡，杜绝无解超模
1. 叠层成本极高，必须完整放弃一回合输出
想要获取印记，整回合只能用变化技能，完全零伤害输出。连续堆叠多层意味着多回合全程挨打，快攻阵容可直接抓住空白输出期压低血量甚至击杀。
2. 72低速+三大主流双倍弱点，天敌遍布环境
飞行、岩石、毒系高速精灵数量多，稳定先手双倍爆发，绝大多数对局撑不到多层印记成型。
3. 印记离场直接清零，无法换场运营拉扯
血量见底切宠保生存时，全部威力加成、能量循环优势直接消失，再次上场需要重新牺牲输出堆叠，容错极低。
4. 草系技能无任何伤害加成，仅负责回能
输出核心完全依赖火系招式，遇上钢、妖精、草等抵抗火系的精灵，哪怕多层印记依旧刮痧，打击面存在硬性短板。
5. 无特性自带常驻续航与减伤，站场全靠单一扎根技能
仅一招小额回血减伤，持续多回合承受物理双倍伤害时，血量下滑速度很快，很难无限叠高层数印记。

### 三、场景定位
1. PVE开荒：标准T2前期挂件
野外飞行、岩石、毒小怪随处可见，很难安稳叠印记；仅慢速水系、地面BOSS战可苟回合成型，其余地图发挥乏力，无法单人通关。
2. PVP天梯：特化慢速消耗对策卡
对战纯肉盾、叠强化慢速体系时成型后压制力极强；面对主流高速快攻队伍强度暴跌，不具备通用上分能力。

## 八、综合总结
1. 完全落实你的修改需求：魔攻130、魔防100，爆辣印记每层提升火系威力30，其余设定全部保留；
2. 一降一调平衡了前后强度：压低基础输出削弱前期能力，小幅提升魔防给足叠层空间，拉高单层印记收益放大长线上限；
3. 叠层代价、低速多弱点、印记离场清空等核心制衡全部保留，不存在全局无解T0强度，快慢对局克制关系清晰，梯度分层稳定，可直接定稿使用。
