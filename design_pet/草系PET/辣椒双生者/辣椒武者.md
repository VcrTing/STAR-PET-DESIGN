# 辣椒武者 变体终稿（草+火物攻手，特性同辣椒炮手【爆辣蓄印】）
## 一、基础档案
名称：辣椒武者
属性：草 / 火
生态：辣椒主干拟人武者，躯干是粗壮老椒杆，手臂生长两根超长硬质细长辣椒，形似双刃长剑；不用投掷炸弹，手持椒刃近战劈砍、突刺，周身裹挟高温辣焰。栖息山间椒林，擅长高速近身缠斗。
进化链：嫩椒武徒 → 辣椒武者（最终形态）
定位：高速蓄力物攻特化，前期T2刮痧，长时间叠满爆辣印记后输出上限极高；飞行、岩石、毒系高速快攻为天然克制天敌，整体不超模。
硬性固定数值：速度110，物攻核心，沿用同族特性【爆辣蓄印】

## 二、定型种族值（对标辣椒炮手调整，适配高速物攻定位）
精力110 / 物攻120 / 魔攻70 / 物防92 / 魔防100 / 速度100
种族总和：110+120+70+92+100+110 = 592
### 面板拆解
1. 物攻130标准输出底子，速度拉至110上游高速，先手权充足，区别于低速炮台辣椒炮手；魔攻彻底舍弃，纯物攻单路线；
2. 魔防100、物防92均衡双抗，血量110中等容错，法系承伤更稳，但物理克制单位（飞行、岩石）双倍伤害依旧压血明显；
3. 草火双属性不变，进攻克制水、岩石、地面、冰、虫；防御三重双倍弱点：飞行、毒、岩石。
推荐性格：开朗（+速度-魔攻）

## 三、两段外观
1. 一阶·嫩椒武徒：纤细嫩椒躯干，短小嫩椒短刃，动作笨拙，仅能简单挥砍。
2. 二阶·辣椒武者：高大椒杆人形武者，藤蔓缠绕成武打劲装；双手各握持一根坚硬细长暗红辣椒，椒尖常年燃烧橙红辣火，挥砍时焰风撕裂空气，近战高速连击。

## 四、专属特性【爆辣蓄印】（和辣椒炮手规则完全一致）
1. 本回合全程未释放任何攻击招式（仅用防御、干扰、回血变化技能），回合结束获得1层爆辣印记；本回合出手攻击则无法获取印记。
2. 每层爆辣印记常驻效果：
   ① 自身所有火系技能威力+30，无层数上限；
   ② 每释放一次草系技能，立刻回复2点能量，维持技能循环。
3. 切换离场、精灵阵亡直接清空全部爆辣印记，重新上场需要放弃输出回合重新堆叠。
4. 仅护盾、扎根、降速、回血等变化技能可安全蓄力叠印；物攻近战招式属于攻击技能，使用后本回合无法拿印记。

## 五、草+火双属性攻防
进攻双倍克制：水、岩石、地面、冰、虫
防御双倍致命弱点：飞行、毒、岩石
属性抵抗：草、电、钢、妖精

## 六、适配配招（近战椒刃物攻体系）
1. 焰椒突刺（火系物攻130，核心近战输出，每层印记威力+30）
2. 藤椒连斩（草系物攻125，释放回复2能量，维持循环续航）
3. 椒根稳架（防御变化，2回合减伤25%，回合末回血6%，蓄力叠印记专用）
4. 辣雾滞速（干扰，降低敌方1级速度，进一步拉开速度差距）

## 七、全方位强度评价，是否超模
### 前置结论：整体依旧可控不超模，机制逻辑不变，只是从低速炮台改为高速蓄力近战，前期T2、长线成型高上限的框架不变。
### 一、相比辣椒炮手的优势提升
1. 速度110高速梯队，绝大多数慢速肉盾、叠层精灵稳定先手，拥有主动拖回合蓄力的空间，不用全程被动挨打；
2. 物攻输出节奏更快，成型后高速连续近战收割，残局滚雪球能力优于慢速炮台；
3. 物防小幅上调，面对水系、地面物理单位站场容错更高，更容易存活叠多层印记。

### 二、不变的硬性制衡，锁死强度杜绝超模
1. 叠印代价不变：拿一层印记必须整回合放弃输出，纯开护盾/干扰，高速只是能选择苟活时机，不能规避“零输出空白期”短板。连续叠多层等于多回合无伤害，对手持续压低血量。
2. 三重主流双倍弱点天敌不变：飞行、岩石、毒系大量精灵速度≥110，可同步先手打出双倍爆发，快速压残甚至击杀，打断叠层节奏。
3. 印记离场直接清零，无法换场存层运营，血量见底被迫换宠就要从头叠印记，容错上限低。
4. 增益限制没变：仅火系物攻享受每层+30威力，草系招式只回能无任何伤害加成；面对钢、草、妖精等抵抗火系的目标，哪怕多层印记依旧刮痧。
5. 无自带续航、弱化免疫，仅依靠一招小额回血减伤，长时间承受物理双倍伤害血量下滑很快，很难无限堆叠高层印记。

### 三、分场景精准定位
1. PVE开荒：前期标准T2蓄力挂件
前期野外飞行、岩石、毒高速小怪众多，容易被先手压制；仅慢速水系、地面BOSS战能安稳叠印成型，打出高额近战爆发，无法单人通关全地图。
2. PVP天梯对战：高速特化蓄力对策卡
对战慢速肉盾、叠强化消耗队时成型后压制力极强；对战主流飞行、岩石快攻体系容易被同步先手爆发限制，很难叠满多层印记，不属于通用上分核心。

## 八、综合总结
1. 完全满足变体设计需求：细长辣椒椒刃近战武者、草火物攻手、速度110，沿用原版爆辣蓄印特性完整规则；
2. 高速模板小幅提升叠层生存空间，但叠印代价、属性天敌、印记清零、输出限制等核心制衡全部保留，不存在无解T0超模强度；
3. 和远程炮台辣椒炮手形成清晰分工：一个低速远程轰炸、一个高速近战连击，同族机制统一、打法区分明显，丰富队伍搭配，不破坏整体精灵梯度分层，可直接定稿使用。
