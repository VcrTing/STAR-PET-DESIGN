## 三、定型种族值（修正数值错误）
精力145 / 物攻90 / 魔攻90 / 物防80 / 魔防80 / 速度30
种族总和：515
### 数值说明
1. 物攻90、魔攻90数值完全均等，均衡双输出模板，仅具备基础补伤能力，无高额斩杀爆发，核心价值不在输出；
2. 速度固定30极低速，永远后手行动，无法先手铺增益、控场，只能后手依靠叠层慢慢提升自身坦度；
3. 精力145高额血量打底，搭配可无限堆叠的双防，长线承伤容错极高，完美契合坦克定位；
4. 基础物防80、魔防80初始耐久中等，必须依靠特性叠层才能成型，前期坦度普通，叠满层数后硬度质变。

悠闲（+精力-速度）、狂妄（+物攻-魔防）
### 天赋推荐
精力、物防、魔防三项核心天赋拉满极品，物攻、魔攻、速度无需刻意追求满天赋

## 四、专属特性：枯木蓄韧
完整效果：
己方场上任意精灵释放任意草系技能（输出攻击、变化增益、防控、干扰类招式全部计入叠加条件），枯树干自身永久物防+10、魔防+10，叠层层数无上限；
配套平衡规则：
1. 自身切换离场时，已堆叠的全部双防层数完整保留，仅当自身阵亡后所有叠加层数一次性清零；
2. 全队所有草系招式均可触发叠层，叠层效率极高，快速拉高自身耐久；
3. 防御加成仅作用于枯树干自身，无法给队伍其他精灵提供任何防御增益。

### 特性平衡约束（极低速+草系多重弱点双重锁强度）
无限堆叠双防的机制长线坦度上限很高，但多重短板严格限制对局强度，不会超模：
1. 速度仅有30极低速，全程后手，敌方高速火、冰、金、灵克制精灵可先手持续压低血量，叠层成型前极易被快速打残；
2. 纯草属性四重双倍弱点：火、冰、金、灵，四类属性高频高速输出精灵遍地，克制伤害会大幅削减叠层带来的坦度优势；
3. 无任何自我回血、队伍续航能力，仅靠基础血量与叠层防御承伤，持续多轮高额克制伤害依旧会被慢慢磨死；
4. 自身输出平平，无法快速击杀对手减少承伤压力，极度依赖队友输出，单宠作战完全无力。

2. PVP天梯对战：T2娱乐功能坦克
