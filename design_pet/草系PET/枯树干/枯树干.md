# 枯树干 优化后完整定稿
## 一、基础档案
1. 名称：枯树干（最终形态）
2. 属性：纯草系，平时伪装路边枯木，玩家无法区分，开战拔根作战
3. 栖息：森林小路、山地灌木区，普通野生捕捉宠，无稀有限定
4. 两段进化：一阶幼枯枝 → 二阶枯树干
5. 硬性调整数值：速度上调至30，物攻100、魔攻100，基础物防100、魔防100不变

## 二、定型种族值
精力145 / 物攻90 / 魔攻90 / 物防100 / 魔防100 / 速度30
总和：145+100+100+100+100+30 = 555
### 面板改动说明
1. 速度10→30：依旧全场低速梯队，绝大多数对手稳定先手，仅小幅降低被超速碾压的极端情况；
2. 物攻66→100、魔攻64→100：具备基础输出能力，不再完全零伤害，但无任何增伤机制，输出仅中游偏下；
3. 双防、血量完全保留原版100/145，裸身耐久普通，必须依靠特性叠层才能变硬。
推荐性格：悠闲（+物防-速度）/狂妄（+魔防-速度）；努力：252精力、252物防、6魔防

## 三、两段外观（无改动）
一阶·幼枯枝：细小枯枝埋于路边草丛，和自然杂草枯枝完全一致；
二阶·枯树干：粗壮干裂枯木躯干，扎根路面伪装死树，战斗拔出根茎，树皮、枯枝用来格挡伤害。

## 四、专属特性【枯木蓄韧】优化规则
己方场上任意精灵释放**任意草系技能（威力输出/变化/防控/干扰全部计入）**，枯树干自身永久物防+10、魔防+10，层数无上限；
1. 加成切换离场不清除，仅自身阵亡后全部层数清零；
2. 全队草系技能全覆盖计数，叠层速度比原版更快；
3. 仅自身享受双防加成，无法给队友提供任何增益。

### 制衡枷锁（防止叠层无解）
1. 纯草系五大双倍弱点：火、飞行、冰、毒、虫，哪怕叠多层双防，吃到克制双倍伤害依旧快速掉血；
2. 基础速度仅30，环境高速火/飞/冰精灵稳定先手，叠层过程会持续承受高额克制伤害，很容易没叠成型就残血；
3. 自身无续航、无减伤护盾常驻，裸身承伤压力大；
4. 脱离多草系队伍，特性直接白板，双防永远只有基础100，强度暴跌。

## 五、纯草系属性攻防（不变）
进攻克制：水、土
防御5个2倍弱点：火、飞行、冰、毒、虫
防御抵抗：水、土、电

## 六、配招（兼顾输出、自保、叠层）
1. 腐木抽打（草物攻威力120，可触发叠层）
2. 毒藤缠绕（草魔攻威力115，可触发叠层）
3. 草木扎根（草系防御变化，回血5%，计入叠层）
4. 腐木屏障（草系免控防控，计入叠层）

## 七、完整强度评价
### 一、本次优化带来的小幅提升
1. 双攻拉到100，拥有稳定基础输出，不再只能纯挨打，单人清理低克制小怪有一定效率；
2. 速度30小幅提升，少量低速土、冰怪能和它持平，不会全场永远最后出手；
3. 所有草系技能都能叠层，变化、防控、输出全部计数，多草队叠双防速度大幅加快，长线BOSS成型更快，整活体验更好。

### 二、多重硬性短板牢牢锁住强度，不会超标、不会挤压其他精灵
1. **成型前裸身面板平庸，弱点太多极易暴毙**
基础双防只有100，五大主流属性双倍克制，开荒随处可见火系、飞行野怪，开局先手双倍伤害，经常叠3～4层就残血，很难叠到高额双防区间。
2. 速度30依旧属于低速梯队，主流高速输出全程压制
水晶蝶、六翼火蝶等高速宠稳定先手，每回合稳定压低血量，不给安稳叠层的空间。
3. 输出仅中游下限，无任何增伤机制，无单刷能力
双攻100无威力加成，打花草土龟、极冰雪熊等高耐久肉盾持续刮痧，必须搭配其他核心输出宠。
4. 泛用性极低，绑定草系队伍
队伍缺少草系精灵时特性完全作废，只是普通均衡肉盾，混合阵容完全没有出场价值，无法替代花草土龟、仿石蘑菇这类泛用土草前排。
5. 无团队辅助能力，仅自身叠防御
对比花草土龟离场给全队草/土+30双抗、萤花仙全队每回合回PP，枯树干只能强化自己，队伍贡献度极低。

### 三、分场景定位
1. PVE开荒：T2娱乐特化肉盾
单拎出来强度一般，必须搭配萤花仙、仿石蘑菇、花草土龟组成多草联防队，依靠全队草系技能快速叠双防打长线BOSS；前期火、飞行小怪极易压制它，不能作为开荒主力。
2. PVP天梯对战：T3整活挂件
仅纯草消耗娱乐队可用；天梯主流火、飞行快攻体系完美克制，上场容易被先手压残，很难叠高层双防，完全不具备上分能力。

## 八、综合总结
1. 完全符合你的优化要求：双攻100、速度30，全部草系技能均可叠加每层10点双防；
2. 相比旧版小幅提升输出与叠层效率，但**五大双倍弱点、低速、成型慢、绑定草队、无团队增益**多重制衡完整保留，整体强度可控，不存在前期无敌碾压其他精灵的问题；
3. 定位草系专属长线娱乐肉盾，机制联动趣味高，但使用门槛高、天敌众多，和花草土龟、仿石蘑菇、极冰雪熊形成清晰强度分层，各精灵各司其职，环境平衡无风险，可直接定稿。
