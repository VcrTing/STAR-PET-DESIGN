# 花草土龟 最终优化定稿（特性修改：离场给草 / 土系 + 30 固定物防、魔防 + 强度完整评测）

## 一、基础设定不变

1. 属性：土 + 草，新手村森林碎石泥滩栖息，和壤孢巨蕈、萤花仙同区域捕捉
2. 三段进化：
一阶：泥苔小龟｜二阶：厚壤苔龟｜三阶：**花草土龟**（终形态龟背完整覆盖野花、苔藓、蕨类，埋土伪装）
3. 固定种族值（无改动）
精力 150 / 物攻 80 / 魔攻 90 / 物防 130 / 魔防 120 / 速度 50
总和：620
培育推荐：悠闲（+ 物防 - 速度）/ 狂妄（+ 魔防 - 速度），努力精力 252、物防 252，剩余 6 魔防

## 二、外观不变（仅复述核心设定）

终形态花草土龟：厚重泥质圆龟甲，表层堆积腐土，整片花草植被铺满背部；常态半埋泥土，仅花草龟背露出，静止和林间泥土草丛完全融为一体；四肢硬化泥甲，周身萦绕泥土青草薄雾。

## 三、修改后专属特性【沃土馈赠】（固定30双防数值加成，替换原 25% 百分比双抗）

### 完整规则

1. 触发条件：自身**主动切换离场** 或 **被击杀阵亡**，两种场景均可触发；单局同一只花草土龟整场战斗仅触发 1 次，离场 + 死亡不会叠加两次增益。
2. 增益效果：下一只登场精灵**仅当属性为草 / 土**时，直接永久获得 **物防 + 30、魔防 + 30**；若下一只不是草、土属性，本次增益直接作废，不延后、不保留。
3. 增益时效：该草 / 土精灵本场全程生效；再次切换离场后，30 点双防加成清除。
4. 控制状态不阻断触发：冰冻、睡眠、恐惧被控状态下阵亡 / 换宠，依旧正常触发沃土馈赠。
