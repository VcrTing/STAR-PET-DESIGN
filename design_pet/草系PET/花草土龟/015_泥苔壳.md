# 泥苔壳 完整完善定稿（纯草｜花草土龟前置精灵，图鉴015）
## 一、基础设定
0. 图鉴编号：015
1. 属性：纯草
2. 栖息点位：新手村森林碎石泥滩、湖边浅水沿岸，与泥苔小龟、莹花籽、小枯树干同区域栖息，三阶花草土龟的中间进化形态
3. 整体定位：低速过渡轮转坦克，共享【沃土馈赠】完整特性，面板全面大幅削弱，强度T3，37级进化图鉴016花草土龟
4. 体型尺寸：厚重低矮小型泥龟，体重偏重，躯体最高点仅抵达人类小腿中下部，体型远小于三阶花草土龟
5. 身高区间：0.20m ~ 0.32m，体重区间：70kg ~ 92kg
6. 性情设定：老实怯懦，警惕性极强，感知人类靠近立刻趴在原地伪装苔藓；人类彻底离开视野后，才会缓慢爬行觅食，绝不主动发起攻击
7. 稀有度：新手村湖边普通野生精灵，刷新数量适中，普通捕捉球即可稳定捕获
8. 进化规则：37级进化为 → 花草土龟
9. 战斗行为：半截躯体埋进滩涂泥土，依靠覆满苔藓的薄泥龟壳承受伤害，泥爪拍击、淡苔藓孢子吐息作为基础输出；依靠主动换宠、阵亡触发特性，给上场草/土精灵提供防御加成，自身耐久偏低，无法长时间站场承伤

## 二、外观
二阶形态：泥苔壳
圆润轻薄泥质龟甲，外壳仅覆盖一层厚实深绿色苔藓，无野花、蕨类植被，仅能伪装路边成片苔藓堆；躯干埋土后只剩布满苔藓的龟背露出，和滩涂青苔环境高度融合。
四肢短粗覆薄泥层，周身仅萦绕淡淡的泥土薄雾，无花草特效；静止伪装时完全贴紧地面，移动时爬行速度缓慢。
区别于三阶花草土龟：无花卉、蕨类装饰，龟壳单薄，体型矮小，伪装载体仅局限于青苔。

## 三、定型种族值（总值控制370区间）
精力92 / 物攻52 / 魔攻60 / 物防74 / 魔防70 / 速度22
种族总和：370
### 数值说明
1. 物攻52、魔攻60输出能力薄弱，仅能清理新手区域最低等级野怪，无斩杀能力，输出仅作补充；
2. 速度22极低速，全程后手行动，敌方高速克制精灵可稳定先手压制，很难安稳站场触发特性；
3. 物防74、魔防70基础耐久中等偏低，精力92血量单薄，面对双倍克制伤害极易残血，很难撑到换宠触发沃土馈赠；
4. 总种族值370，标准前期过渡杂鱼面板，坦度、输出全方位缩水，和三阶620种族值形成巨大强度差距。
### 性格推荐
悠闲（+精力-速度）
### 天赋推荐
精力、物防、魔防三项核心天赋拉满极品，物攻、魔攻、速度无需刻意培养

## 四、专属特性：沃土馈赠（机制与花草土龟完全不变）
完整效果规则：
1. 触发条件：自身主动切换离场、被敌方击杀阵亡，两种场景均可正常触发效果；单局对战内同一只泥苔壳全程仅能触发1次特性，离场+阵亡不会叠加两次增益；
2. 增益判定：下一只登场精灵属性为草/土系时，直接永久获得物防+30、魔防+30；若下一只登场精灵非草、土属性，本次增益直接作废，不延后储存、不保留至下一次换宠；
3. 增益时效：拿到buff的草/土精灵本场对战全程持有30点双防加成，该精灵再次切换离场后，加成直接清空；
4. 负面阻断豁免：自身陷入冰冻、睡眠、恐惧任意控制状态时换宠或者阵亡，沃土馈赠依旧正常触发，控制不会封锁特性。

### 特性平衡约束（极低面板锁死强度，机制完整但实战收益有限）
虽和高阶花草土龟拥有一模一样的支援机制，但基础全方位短板限制强度，不会破坏前期数值平衡：
1. 血量、双防基础数值偏低，高速火、冰、金、灵克制精灵先手双倍伤害，经常来不及换宠就被直接击杀，无法触发特性支援队友；
2. 速度仅有22，永远后手挨打，没有主动操作空间，只能被动承伤等待换宠时机；
3. 自身输出刮痧，无法快速压低敌方血量减少承伤压力，单宠作战完全无作用，必须搭配草/土队友才能小幅发挥特性价值。

## 六、生态与抓捕规则
1. 刷新逻辑：新手村湖边泥滩、青苔坡海量刷新一阶泥苔小龟，少量刷新二阶泥苔壳，野外无法直接捕捉三阶花草土龟；
2. 抓捕道具：普通捕捉球百分百稳定捕获，玩家刚抵达湖边区域即可获取；
3. 伴生精灵：常和莹花籽、小枯树干、韧甲虫混居湖边滩涂，生态互补；
4. 行为特征：平时趴在泥土苔藓层静止伪装，人类靠近完全不动；人类离开视野后，才缓慢爬行寻找水草、青苔进食，不会主动靠近玩家。

闪光泥苔壳龟甲为浅灰泥色，表层苔藓转为淡青绿色，周身泥土薄雾浅白；
闪光个体区间微调：身高趋近区间上限0.38m，体重趋近区间下限70kg；基础精力小幅+3，速度依旧22，不改变低速过渡杂鱼定位。

## 八、场景强度定位
1. PVE新手湖边开荒过渡：T3合格小型轮转坦辅
前期野怪伤害低，搭配莹花籽、小枯树干等草系精灵，偶尔换宠触发沃土馈赠给队友提供防御加成，仅临时过渡使用，37级进化后强度大幅提升。
2. PVP天梯对战：完全无上场价值
血量、双防、速度、输出全面拉胯，极易被高速克制精灵秒杀，无法组建成型联防体系。

## 九、适配队伍搭配推荐

火系、冰系、金属、灵系高速输出精灵，双倍克制高额伤害，可快速压低泥苔壳血量，甚至直接秒杀，彻底废掉支援特性。

## 十、整体总结
1. 完全匹配设定需求：图鉴015二阶进化形态泥苔壳，37级进化花草土龟，种族总值370区间，特性【沃土馈赠】机制完全不变；龟背仅覆盖苔藓无花草，仅能伪装路边青苔，遇人静止伪装、人走缓慢觅食，身高仅到人类小腿中下部；
2. 单薄青苔龟壳矮小形象，和三阶铺满花草、体型厚重的花草土龟形成清晰外形、体型梯度反差，三段龟类进化成长逻辑通顺；
3. 完整继承草系联防支援特性，但极低血量、薄弱双防、极低速多重短板锁死前期强度，不存在超模无解对局；
4. 定位仅为新手湖边过渡小型轮转坦克，作战能力有限，必须进化为花草土龟才能解锁完整联防坦辅强度，无天梯对战使用价值。
