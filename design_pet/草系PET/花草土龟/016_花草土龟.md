# 花草土龟 完整完善定稿（纯草｜三段进化终形态轮转坦克，图鉴016）
## 一、基础设定
0. 图鉴编号：016
1. 属性：纯草
2. 栖息点位：新手村森林碎石泥滩、湖边浅水沿岸，和壤孢巨蕈、萤花仙共享同一片野外捕捉区域
3. 整体定位：低速高耐久轮转功能坦克，标准T1梯队；依靠换宠、阵亡给草/土系队友提供高额双防加成，适配长线消耗联防体系，性格老实憨厚
4. 体型尺寸：躯体厚重分量极重，整体身高不高，躯体最高点仅到人类臀部以下，敦实低矮龟型体态
5. 身高区间：0.35m ~ 0.68m，体重区间：160kg ~ 190kg
6. 性情设定：天性老实憨厚，胆子极小，发现人类靠近会立刻埋土或者缓慢逃离，绝不会主动发起攻击
7. 稀有度：新手村常规野生精灵，无限定、无BOSS，普通捕捉球即可稳定捕获
8. 进化规则：完整三段进化链
一阶泥苔壳37级→二阶花草土龟（本终形态）
9. 战斗行为：常态半埋泥土降低受到的伤害，依靠厚重泥龟壳承受敌方攻击，物攻泥爪拍击、魔攻花草孢子吐息均衡输出；主打轮换离场触发特性，为后续登场草、土精灵提供防御buff，自身不适合单宠长时间站场

## 二、外观
终形态：花草土龟
厚重圆润泥质龟甲为主体，甲面堆积厚实腐殖泥土，整片野花、苔藓、蕨类植被完整铺满整个背部龟壳；平时习惯半截身子埋进滩涂泥土，只露出长满花草的龟背，静止状态下和林间泥土、湖边草丛完美融合，肉眼难以分辨。
四肢覆盖硬化岩土甲片，行动缓慢沉重；周身常年环绕淡淡的青草泥土薄雾，切换离场触发特性时，周身泥土花草雾气会大量扩散。

## 三、定型种族值
精力150 / 物攻80 / 魔攻90 / 物防130 / 魔防120 / 速度50
种族总和：620
### 数值说明
1. 物攻80、魔攻90数值均衡接近，具备基础补伤能力，输出并非核心职能，仅作为次要手段；
2. 速度固定50低速梯队，无法抢占先手，只能后手承伤，依靠轮换机制发挥特性价值；
3. 物防130、魔防120高额基础双防，搭配150充沛血量，自身基础坦度顶尖，能够稳定扛伤触发离场/阵亡buff；
4. 种族总值620，均衡耐久面板适配轮转坦克定位，强度可控不超模。
### 性格推荐
悠闲（+精力-速度）、狂妄（+物攻-魔防）
### 天赋推荐
精力、物防、魔防三项核心天赋拉满极品，物攻、魔攻、速度无需刻意追求满天赋

## 四、专属特性：沃土馈赠
完整效果规则：
1. 触发条件：自身主动切换离场、被敌方击杀阵亡，两种场景均可正常触发效果；单局对战内同一只花草土龟全程仅能触发1次特性，离场+阵亡不会叠加两次增益；
2. 增益判定：下一只登场精灵属性为草/土系时，直接永久获得物防+30、魔防+30；若下一只登场精灵非草、土属性，本次增益直接作废，不延后储存、不保留至下一次换宠；
3. 增益时效：拿到buff的草/土精灵本场对战全程持有30点双防加成，该精灵再次切换离场后，加成直接清空；
4. 负面阻断豁免：自身陷入冰冻、睡眠、恐惧任意控制状态时换宠或者阵亡，沃土馈赠依旧正常触发，控制不会封锁特性。

### 特性平衡约束（低速短板+纯草四重弱点多重制衡）
高额双防支援机制功能性极强，但多重短板锁住整体强度，不存在无解联防：
1. 速度仅50低速，敌方高速火、冰、金、灵克制精灵可先手持续压制，容易未触发特性就被快速击杀，错失给队友挂buff的机会；
2. 纯草属性四重双倍弱点：火、冰、金、灵，四类高频高速输出精灵能快速击穿自身高额双防，限制持续站场承伤；
3. 特性加成仅服务草、土队友，队伍缺少对应属性精灵时，沃土馈赠完全失效，自身失去核心战术价值；
4. buff仅单场单次生效，换宠即清空，无法无限叠加防御，长线多轮换宠体系收益存在上限。

## 五、纯草属性攻防（严格套用专属11属性克制倍率表）

### 防御抵抗&免疫
草抵抗：水、电、土；无属性免疫

## 六、生态与抓捕规则

## 八、场景强度定位
1. PVE新手村/山地开荒：T1优质轮转坦辅
野外AI不会高速集火，搭配枯树干、铁甲盔、韧甲虫等草/土系精灵，换宠体系稳定触发沃土馈赠，全队草土坦度大幅提升，长线推图承伤压力骤减；自身高额双防可以单独清理水、土系野怪。
2. PVP天梯对战：T1功能型联防坦克
草土专属高额双防支援，构建慢速消耗联防体系；但低速短板、四重属性弱点十分明显，对手高速火/冰/金/灵宠可针对性突破，缺少草土队友时完全废核，存在清晰破解思路。
