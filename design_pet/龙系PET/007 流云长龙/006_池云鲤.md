# 池云鲤 完整完善定稿（水属性｜流云长龙一阶初始形态，图鉴006，二段进化链：池云鲤→流云长龙）
## 一、基础设定
0. 图鉴编号：006
1. 属性：纯水
2. 栖息点位：高山云海下方山间湖泊、云雾溪流，水域浅滩定点刷新，成年流云长龙栖息的高空云海下方水域幼体形态
3. 整体定位：中速前期均衡过渡双刀，共享【鎏金龙云印】同款特性，基础面板全面削弱，输出上限低，强度T2，仅作为过渡精灵，40级进化图鉴007流云长龙
4. 体型尺寸：体长仅成年人大腿长度，身形小巧圆润，鱼型躯体无龙类肢体
5. 体长区间：0.60m ~ 0.75m，体重区间：22kg ~ 30kg
6. 性情设定：温和胆小，常年成群在云雾湖面游动，不会主动攻击人类，受到惊扰会潜入水底躲避，被逼入战斗才会反击
7. 稀有度：山地云雾水域普通野生精灵，非BOSS、非限定
8. 进化规则：等级37级进化为图鉴007·流云长龙，全系列仅两段进化
9. 战斗行为：依靠鱼尾游动浮空/水面作战，水刃物攻、云雾水流魔攻双输出；频繁切换离场叠加印记，依靠偶数回合小幅增伤打消耗，自身耐久不足无法长期站场
10. 定位：轮转手

## 二、外观
初始形态：池云鲤
圆润流线型淡水鱼体态，无龙角、龙须、龙鳍，通体浅白淡蓝鱼鳞，体表漂浮细碎小云状水雾纹路；整体长度仅至人类大腿，身形短巧。
头部小巧圆钝，尾部分三层轻薄半透明水云鱼鳍，游动时飘散淡淡的白雾；周身环绕稀薄水汽云雾，无流云长龙鎏金装饰，整体素雅清淡。
回合特效区分：奇数回合周身水汽黯淡，无增伤光效；偶数回合鱼鳞云纹泛淡蓝光，印记层数越多光泽越亮。

## 三、定型种族值（全面下调，过渡宠均衡削减面板）
精力76 / 物攻72 / 魔攻72 / 物防60 / 魔防60 / 速度76
种族总和：416
### 数值说明
1. 物攻72、魔攻72数值均等，继承双刀体系，但双输出面板大幅低于进化型，无斩杀能力，仅能小额持续消耗；
2. 速度76中速梯队，对比流云长龙112高速差距明显，很难稳定抢占切宠节奏；
3. 物防60、魔防60双耐久偏低，缺少高额承伤能力，不能长时间单宠站场叠印记；
4. 精力76血量单薄，容错率低，面对克制伤害极易残血。
### 性格推荐
急躁（+速度-物防）、天真（+速度-魔防），优先拉高速方便轮换出场叠印记
### 天赋推荐
速度、物攻、魔攻三项核心天赋拉满极品，精力、双防天赋无需追求满值

## 四、专属特性：鎏金龙云印
完整效果（和进化体流云长龙机制完全一致）：
1. 登场判定：首发上场、切宠离场后再次切回，自动获得1层龙云印记；切换下场不会清空已堆叠印记，反复轮换可无限叠加层数；
2. 叠层补充：任意水系物攻/魔攻技能成功命中敌方，额外叠加1层龙云印记；
3. 印记固定增益：每持有1层印记，**偶数回合释放的水系招式威力提升30%**；奇数回合无任何增伤加成；
4. 负面清空机制：自身陷入睡眠、冰冻、恐惧任意控制异常时，立刻清空全部龙云印记层数。

### 特性平衡约束（低面板+中速+水属性弱点多重锁死强度）
虽拥有和流云长龙完全相同的印记叠加机制，但基础面板薄弱限制整体强度：
1. 速度仅有76，大量高速精灵可先手压制，打断轮换叠层节奏；76低血量+60双防，偶数回合爆发前容易被直接击杀；
2. 纯水属性存在草、电双重双倍弱点，野外高频草、电精灵完美克制池云鲤，生存压力大；
3. 物攻魔攻仅72，即便多层印记叠加，偶数回合增伤后也无法打出高额爆发，只能处理低等级野怪，后期输出乏力。

## 五、纯水属性攻防（严格套用专属11属性克制倍率表）

水克制：火、土；水抵抗：草、电
针对山地火系、地面系野怪输出有优势，前期开荒克制覆盖面充足。
### 防御弱点（双重双倍克制，强力制衡）
水双倍弱点：草、电，两类属性前期地图随处可见，大量高速精灵克制池云鲤。
### 防御抵抗&免疫
水抵抗：草、电；无属性免疫

## 六、生态与抓捕规则
1. 刷新逻辑：仅高山云雾湖泊、山间溪流刷新，野外只能捕捉池云鲤，无法直接捕获流云长龙；
2. 抓捕道具：普通捕捉球即可稳定捕捉，玩家抵达山地湖泊区域即可获取；
3. 伴生精灵：成群结伴在浅滩游动，无强势伴生精灵；
4. 行为特征：平日安静在水面漂浮游动，人类靠近只会潜水躲避，不会主动开战；被逼对战后会不断切换离场叠印记游击消耗。

闪光个体区间微调：体长趋近区间上限0.75m，体重趋近区间下限22kg；基础速度小幅+3，速度79，依旧为中速，不改变双刀、偶数回合爆发核心机制。

## 八、场景强度定位

前期野怪输出偏低，AI不会刻意控场清空印记，依靠水系克制火、土野怪，偶数回合增伤平稳清理小怪，40级进化后强度大幅跃升。
2. PVP天梯对战：无上场价值

## 十、整体总结
1. 完全匹配设定需求：图鉴006、二段进化一阶初始形态、纯水属性，体长仅人类大腿长度，共享【鎏金龙云印】完全不变特性，种族值整体下调适配过渡定位，40级进化流云长龙；
2. 小巧云雾鱼鲤形象，和进化后卡车长度云龙长龙形成体型、属性巨大反差，水域幼体→高空龙形的成长生态逻辑完整；

4. 定位仅为山地水域前期过渡双刀消耗宠，作战能力有限，必须进化为流云长龙才能解锁完整爆发强度，无天梯对战使用价值。
