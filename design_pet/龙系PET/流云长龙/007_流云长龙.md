# 流云长龙 完整完善定稿（纯龙｜高速轮换双刀爆发输出｜单段终形态 图鉴007）

0. 图鉴编号：007
1. 属性：纯龙
2. 栖息点位：高空云海、高山云层之巅，常年云雾缭绕的高空专属精灵，极少落地
3. 整体定位：高速轮换型均衡双刀输出，标准T1上游强度；依靠反复切换出场叠加龙云印记，在偶数回合打出高额龙系爆发，物攻魔攻双面板均等，对战节奏完全由自身速度掌握
4. 体型尺寸：全长等同于大型货运卡车，身形蜿蜒修长，整体线条柔和流畅，无厚重躯体与凶戾尖角

6. 性情设定：温润优雅，无主动攻击性，仅被敌人挑衅、主动开战时才会释放龙系力量反击，喜欢穿梭云层游荡

8. 进化规则：无前置进化形态，自身为独立单段最终形态
9. 战斗行为：全程浮空云海间游动作战，依靠修长身躯灵活迂回，物攻龙爪冲击、魔攻云龙吐息双输出手段交替释放，擅长频繁切换离场叠层，抓偶数回合爆发斩杀对手
10. 定位：轮转手

## 二、外观
完全体：流云长龙
全身布满华贵顺滑的乳白色鳞甲，整条长龙布满连绵不断的银白云纹纹路，纹路会随云雾微光流动；头部小巧精致，无龙角，两对细长金色龙须垂至胸腹位置，随风轻晃；尾部生长多层半透明金箔质感云鳍，游动时如云絮散开。
整体全为流畅柔和曲线设计，不存在厚重四肢、坚硬狰狞尖角，气质仙气温润；周身永久环绕稀薄流云，飞行时身后拖曳大片银白云雾轨迹。
战斗特效区分：奇数回合周身云雾浅淡，无增伤光效；偶数回合全身云纹、金须、尾鳍同步亮起金光，龙云印记层数越多，金光亮度越强。

## 四、专属特性：鎏金龙云印
完整效果：
1. 登场判定：首发上场、切换离场后再次切回战场，自动获取1层龙云印记；精灵切换下场不会清空身上已堆叠印记，反复轮换出场可无限叠加层数；
2. 叠层补充：任意龙系物攻/魔攻技能成功命中敌方目标，额外叠加1层龙云印记；
3. 印记固定增益：每持有1层印记，**偶数回合释放的所有龙系招式威力提升30%**；奇数回合无任何增伤加成；
4. 负面清空机制：自身陷入睡眠、冰冻、恐惧任意控制异常时，立刻清空全部龙云印记层数。

### 特性平衡约束（高速爆发机制多重制衡，避免超模）
1. 输出完全绑定偶数回合，奇数回合零增伤，伤害断层明显，对手可抓住奇数回合联防、抬血、换克制宠规避爆发；
2. 被控直接清空全部印记，一旦被控制会彻底丢失全部叠加层数，前期轮换叠层的优势直接清零；
3. 纯龙属性仅有两项抵抗，双重弱点短板清晰，冰、龙系高速克制精灵可先手压制，限制频繁切宠叠层的操作空间；
4. 双防无高额加成，不能长期站场持续叠层，必须依靠轮换游击打法，操作门槛高，新手难以发挥完整强度。
