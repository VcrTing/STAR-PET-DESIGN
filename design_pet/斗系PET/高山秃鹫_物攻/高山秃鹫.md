# 孤穹秃鹫 完整设计（格斗系大鸟，参考老鹰+秃鹫，孤傲高冷无视玩家，物攻手，速度85）
## 一、进化链
一阶：荒岩雏鹫（山崖幼鸟，孤僻独居）
二阶：孤穹秃鹫（40级进化，完全体，纯斗系）

## 外形设定
### 荒岩雏鹫
通体暗灰褐绒毛，头顶少量暗红秃斑，爪子锋利；独自栖息悬崖石缝，从不集群，玩家靠近就侧头无视，一动不动，毫无互动欲望；体型偏小，只会低空滑翔。

### 孤穹秃鹫（最终形态）
1. 原型融合高山苍鹰+荒原秃鹫，头部大片无羽暗红秃皮，眼神冷冽锐利，自带孤傲疏离气场；
2. 羽翼主色炭黑、翅尖泛暗赤纹路，翼展宽大，常年独自盘旋高空悬崖上空，从不与其他鸟类结伴；
3. 行为设定：玩家走到下方、主动靠近时，它只会冷漠侧视，不会主动开战、不会靠近，完全无视主角；只有主动抛出对战诱饵才会俯冲下来交手；战后直接独自飞向远山悬崖，不留停留。
4. 肢体气质：动作沉稳缓慢，无喧闹鸣叫，沉默孤傲，远离所有群居精灵。

## 属性：纯格斗系
### 属性克制
进攻克制：普通、岩石、毒、冰、恶
防守弱点：飞行、超能力、妖精（三大主流克制属性，天然限制强度）
抵抗：虫、岩石、恶

面板解析
1. 物攻142优质物理输出，纯物攻模板，魔攻彻底作废；
2. 速度固定85，中低速，抢不过高速飞行、妖精精灵；
3. 物防偏高适合物理对拼，但魔防偏低，超能、妖精特攻容易打穿；
4. 血量中等，无高额续航，不能长时间站场。

## 选用宝可梦鸟类标准特性：**锐利目光（Keen Eye）**
### 特性【锐目孤睨】（照搬宝可梦锐利目光效果，贴合秃鹫高冷鹰眼设定）
效果：
1. 自身能力不会被对手降低命中等级；敌方无法通过技能、特性削减自身招式命中率；
2. 无视敌方提升的闪避类效果，所有攻击不会被闪避落空。

### 选用理由
1. 正统宝可梦鸟类通用基础特性，强度温和，无爆发增伤、无全队辅助，不会超模；
2. 人设契合：秃鹫高空鹰眼，视野不受雾气、干扰影响，看穿一切闪避手段，孤傲不屑被对手干扰；
3. 强度定位中性，只有稳定输出不miss的小幅保障，无进攻/生存高额加成，搭配三重弱点，稳定T1中下游，不会冲击T0梯队。

### 不推荐鸟类特性排除说明
- 疾风之翼：高速先手强化，强度过高；
- 健壮胸肌：接触招式增伤，物攻提升过大；
- 梦话/不眠：功能性弱，和孤傲猎手人设不搭；
锐利目光最适配高冷独行猛禽定位。

## 标准对战配招
1. 裂岩俯冲（格斗物攻130，俯冲撞击核心输出）
2. 铁翼击（飞行物攻90，补盲克制格斗天敌虫、草）
3. 蓄力沉爪（变化，物攻提升1级）
4. 荒崖固守（变化，物防提升1级，补强物理生存）

## 强度综合评价
1. 单打：T1下游
物攻不错，输出稳定不会miss，但速度85偏慢，飞行、超能、妖精精灵普遍能先手压制；魔防薄弱，特攻招式极易残血；纯格斗打击面存在大量盲点。
2. 组队：二线物攻挂件，非刚需
仅缺少物理输出的慢速物理队可携带，无团队增益，没有联防、治疗、控场能力，可替代物攻手极多。
3. 保值性：稳定命中机制永远有用，但自身短板明显，环境更迭不会成为主流强势精灵。

## 生态习性
栖息高海拔孤悬崖壁，终身独居，领地意识极强，排斥所有其他生物；白天独自盘旋高空搜寻猎物，全程无视路过的玩家；无群居行为，整片山崖只会刷新一只成年孤穹秃鹫。
